# Technical Summary ランキング分類仕様（アーカイブ）

## 1. 目的

**本書はアーカイブ版です。ランキング分類条件の正本は `docs/technical_ranking_spec.md` を参照してください。**

本書は Technical Summary のランキング分類条件の旧版であり、以下の参照先を更新しました：

- **ランキング分類条件の正本：** `docs/technical_ranking_spec.md`
- **表示形式：** `docs/Summery_spec.md`
- **現行実装状況：** `docs/current_implementation_spec.md`

`technical_ranking_spec.md` は、本書の内容にくわえて、Technical指標計算、VWAP定義、
ローソク足型判定、陽線・陰線・上値失速の定義、US Market指標などを一元管理しています。

## 2. 基本方針

- 25日線の上下と VWAP の上下を、D系ランクの主要な状態判定に使う。
- 25日線乖離率は D1 / D2 / D3 の必須条件にしない。
- 25日線乖離率は、反発余地、25日線奪回難易度、戻り売りリスクを示す補助ラベルに使う。
- D2 は「まだ入らない候補」、D3 は「小さく入れる候補」とする。
- 25日線未満かつVWAP上でD3を満たさない銘柄は、25日線距離ATRによりD1a / D1bへ分類する。
- 必須データが欠損した場合は、成立扱いにせず `判定保留` とする。
- すべてのランキングで、場中は現在値、大引け後は当日終値を判定価格に使う。

## 3. D系ランクの判定順

現在値が25日線未満の場合、次の順で判定する。

1. VWAP上なら D3 を判定する。
2. D3不成立なら、25日線距離ATRにより D1a / D1b を判定する。
3. VWAP以下なら D2 を判定する。
4. D1 / D2 / D3 のいずれにも該当しない場合は E とする。

## 4. 全ランク一覧

D1 / D2 / D3 以外は現行分類を維持し、別途改定するまで次を基準とする。

| ランク | 表示名 | 分類の中心 | 行動の中心 |
|---|---|---|---|
| A1 | 位置良好 | 25日線上、VWAP上、過熱なし | 条件付きで買い候補 |
| A2 | 上昇継続 | 25日線上、VWAP上、4〜7%の上昇継続 | 支持線待ち、小さく検討 |
| B1 | 上昇後半 | 上昇幅、3日騰落、レンジ位置が高い | 新規は慎重 |
| B2 | 過熱極大 | 極端な上方乖離、RSI高位、出来高急増 | 新規買いを避け利確優先 |
| C1 | 押し目候補 | 25日線上、VWAP下または接近 | VWAP回復待ち |
| C2 | 崩れ警戒 | 25日線上だが価格構造が悪化 | 買いを待ち崩れを警戒 |
| D1 | 戻り途中 | 25日線下、VWAP上、反転未確認 | 詳細画面でD1a / D1bを表示 |
| D2 | 底打ち候補 | 25日線下、VWAP以下、支持線反発候補 | まだ入らない |
| D3 | 底打ち初動 | 25日線下、VWAP回復、反転確認 | 小さく入れる候補 |
| E | 下落トレンド | 25日線下でD1/D2/D3不成立 | 買い見送り |

## 5. 共通指標

| 指標 | 定義案 |
|---|---|
| 25日線位置 | `現在値 < 25日線` をD系判定の前提とする |
| VWAP位置 | `現在値 > VWAP` をVWAP上、`現在値 <= VWAP` をVWAP以下とする |
| 終端位置 | `(現在値 - 当日安値) / (当日高値 - 当日安値) * 100` |
| 25日線距離ATR | `(25日線 - 現在値) / ATR14`。25日線未満で正値となる |
| 支持線距離ATR | `abs(当日安値 - 支持線) / ATR14` |
| VWAP距離ATR | `(VWAP - 現在値) / ATR14` |
| 出来高比 | `当日出来高 / 20日平均出来高 * 100` |
| VWAP維持時間 | 直近のVWAP上抜け後、連続してVWAP上にいる時間 |
| 判定価格 | 場中は最新5分足の現在値、大引け後は当日の日足終値 |

ATR14 が0または欠損の場合、ATRを使う必須条件は `判定保留` とする。

### 5.1 場中と大引け後の価格選択

- 通常取引の場中は、当日最新5分足の終値を現在値として使う。
- 大引け後は、確定した当日の日足終値を使う。
- 大引け直後で当日の日足終値がまだ取得できない場合は、当日最終5分足の終値を
  暫定終値として使い、価格ソースを `暫定終値` と表示する。
- 前場と後場の休場時間中は、当日最新5分足の現在値を使う。
- 休日または当日足がない場合は、直近取引日の終値を使い、過去日データであることを表示する。
- 判定価格、判定価格の時刻、価格ソースを同じ評価コンテキストに保持する。

## 6. D1 戻り途中 / 25日線奪回待ち

### 6.1 位置づけ

VWAPは回復したが、反転確認は不十分で、25日線が上値抵抗になっている状態。
新規買いを急がず、25日線奪回または上値の確認を待つ。

### 6.2 必須条件

- 現在値が25日線未満
- 現在値がVWAPより上
- D3条件を満たさない

### 6.3 詳細画面のD1サブ分類

D1a / D1b はランキングコードを増やさず、単一銘柄詳細画面だけのサブ分類とする。

| サブ分類 | 条件 | 表示名 | 意味 |
|---|---|---|---|
| D1a | `25日線距離ATR <= 2.0` | `戻り途中・25日線接近` | 25日線奪回を試せる距離だが、利確圧力に注意 |
| D1b | `25日線距離ATR > 2.0` | `戻り途中・25日線遠い` | 25日線奪回まで値幅があり、戻り確認を継続 |

ATR14または25日線が欠損する場合もランキングはD1とし、詳細サブ分類だけを
`D1 判定保留` とする。

### 6.4 表示文

状態に応じて次を組み合わせる。

- `戻り途中`
- `25日線奪回待ち`
- `上値確認中`
- `25日線接近なら利確圧注意`
- `25日線まで距離あり`

### 6.5 売買行動

- 基本は監視継続。
- 25日線接近時は利確圧力を警戒する。
- 追加買いは25日線奪回後を基本とする。
- D1bはD1aよりも25日線奪回までの不確実性が高いため、監視継続を優先する。

## 7. D2 底打ち候補 / 支持線反発待ち

### 7.1 位置づけ

支持線付近で反発の兆候はあるが、VWAPを回復していない状態。
D2は「まだ入らない候補」とし、新規買いは待つ。

### 7.2 必須条件

- 現在値が25日線未満
- 現在値がVWAP以下
- いずれかの支持線について `abs(当日安値 - 支持線) <= 0.35 * ATR14`
- 終値または現在値が、採用した支持線より上へ戻っている
- `VWAP - 1.0 * ATR14 <= 現在値 <= VWAP`
- 除外条件に該当しない

支持線候補は、前日安値、20日安値、75日線、60日安値とする。
25日線は上値抵抗として扱い、D2の支持線候補には含めない。

### 7.3 除外条件

- 支持線を明確に割れている
- 終端位置が40%未満
- 3日連続で安値を切り下げている
- 出来高急増を伴う陰線
- 現在値の直下に有効な支持線がない

推奨する数値定義は次の通り。

| 除外条件 | 推奨初期値 |
|---|---|
| 支持線明確割れ | `当日安値 < 支持線 - 0.35 * ATR14` かつ `判定価格 < 支持線` |
| 3日連続安値切り下げ | 直近3比較の `当日安値 < 前日安値` がすべて成立 |
| 出来高急増の陰線 | 出来高比180%以上、陰線、実体が当日レンジの65%以上 |
| 直下支持線なし | 判定価格より下、かつ1.0ATR以内に支持線候補がない |

### 7.4 25日線乖離ラベル

25日線乖離率は分類条件ではなく、リスク表示に使う。

| 25日線乖離率 | ラベル |
|---|---|
| `-3%以上 0%未満` | 浅押し反発候補 |
| `-8%以上 -3%未満` | 浅押し反発候補 |
| `-15%以上 -8%未満` | 底打ち候補 |
| `-15%未満` | 深掘れ反発候補・リスク大 |

ユーザー案の `-3〜-8%` より浅い `0〜-3%` を未分類にしないため、同じ
`浅押し反発候補` に含める案とする。

### 7.5 表示文と売買行動

- 表示名: `底打ち候補`
- 状態: `支持線反発待ち`
- 行動: `まだ入らない`
- 次確認: `VWAP回復待ち`
- リスク: 25日線乖離ラベルを併記する

## 8. D3 底打ち初動 / 反転確認

### 8.1 位置づけ

VWAPを回復し、価格モメンタムと終端位置から反転初動を確認できる状態。
D3は「小さく入れる候補」とし、通常サイズのエントリーとは区別する。

### 8.2 必須条件

- 現在値が25日線未満
- 現在値がVWAPより上
- 安値切り上げが2回以上
- 高値更新が1回以上
- 終端位置が60%以上
- VWAP上を15分以上連続維持している

出来高比はD3分類の必須条件にしない。単一銘柄詳細画面のD3強弱表示にのみ使う。

### 8.3 推奨追加条件

- 現在値が前日高値または直近抵抗線を試している
- `25日線距離ATR <= 2.0`

推奨追加条件はD3の必須条件にはせず、信頼度または表示ラベルに使う。

### 8.4 25日線乖離ラベル

| 25日線乖離率 | ラベル |
|---|---|
| `-4%以上 0%未満` | 25日線奪回接近 |
| `-8%以上 -4%未満` | 反転初動 |
| `-15%以上 -8%未満` | 深押し反転 |
| `-15%未満` | 急落リバ・戻り売り警戒 |

### 8.5 表示文

成立した条件とリスクに応じて次を組み合わせる。

- `底打ち初動`
- `VWAP回復`
- `安値切り上げ`
- `反転確認`
- `25日線奪回待ち`
- `戻り売り注意`

### 8.6 単一銘柄詳細画面のD3強弱

D3成立後、出来高比によって詳細画面の表示を3段階に分ける。
この強弱はD3ランキング分類を変更しない。

| 詳細表示 | 出来高比 | 表示文 |
|---|---:|---|
| D3強 | 80%以上 | `D3強｜VWAP維持・出来高伴う` |
| D3 | 60%以上80%未満 | `D3｜VWAP維持・出来高やや不足` |
| D3弱 | 60%未満 | `D3弱｜反転形あるも出来高不足` |

出来高比が欠損する場合は `D3｜VWAP維持・出来高N/A` とする。

### 8.7 売買行動

- 小さな試し玉のみ候補とする。
- 25日線奪回前は通常サイズへ増やさない。
- 乖離が大きい場合は、戻り売りリスクを表示してサイズを抑える。
- VWAP割れ、安値切り下げ、支持線割れのいずれかで前提崩れとする。

### 8.8 D系詳細短評

D系の単一銘柄Technical出力は、ランキング共通短評と詳細行を分けず、
詳細分類、状態、主判定を1行の短評にまとめる。ランキング一覧上のコードは
従来どおりD1 / D2 / D3とし、詳細分類は単一銘柄出力だけに使用する。
D2 / D3では25日線乖離ラベルを取得できる場合、主判定の後ろへ補助情報として併記する。

| 詳細分類 | 主判定 |
|---|---|
| D1a | `監視優先。D3化なら小さく可` |
| D1b | `監視優先。深指値は原則不可` |
| D1判定保留 | `判定保留。新規不可` |
| D2 | `支持線反発候補。原則VWAP回復待ち` |
| D3強 | `小さく可。D3内で最有力` |
| D3 | `小さく可。出来高確認` |
| D3弱 | `監視寄り。出来高不足` |

表示例:

```text
短評：D1a 戻り途中・25日線接近｜監視優先。D3化なら小さく可
短評：D2 底打ち候補｜支持線反発待ち｜支持線反発候補。原則VWAP回復待ち
短評：D3強｜VWAP維持・出来高伴う｜小さく可。D3内で最有力｜25日線奪回接近
```

### 8.9 D系詳細戦略判定

戦略判定は、表示時点で売買シグナルが成立したことを示すものではない。
「深押し指値」「前場VWAP回復」「後場VWAP回復」の各シナリオが成立した場合の
行動指針を並べる。前場・後場の区分は取得した5分足の時刻を使用する。

| 短評 | 深押し指値 | 前場VWAP回復 | 後場VWAP回復 |
|---|---|---|---|
| D1a 戻り途中・25日線接近 | **△** 地合い良好なら `支持線〜支持線+0.15ATR`。RRは25日線または直近抵抗線までで判定。安全重視ならVWAP再回復確認 | **△** VWAP回復だけでは不可。`VWAP15分維持＋安値切り上げ＋高値更新` でD3化なら小さく可 | **△** 後場VWAP上維持なら小さく可。25日線接近時は利確圧に注意し、持ち越しは25日線手前で評価 |
| D1b 戻り途中・25日線遠い | **×〜△** 基本は危険。支持線が明確でRR2.0以上なら最小ロットのみ | **△** VWAP上でもD3未達なら監視。入るならD3条件成立後 | **△〜×** 出来高60%以上かつ終端60%以上がなければ見送り |
| D1 判定保留 | **×** ATR距離不明なら `指値算出不可` | **△** D3条件を満たせば小さく可。ただし通常サイズ不可 | **△〜×** 判定材料不足のため原則見送り |
| D2 底打ち候補 | **△** `支持線〜支持線+0.15ATR`。地合い良好時のみ。RR1.5以上なら試し可 | **△** VWAP15分維持なら試し玉候補。安値切り上げ、高値更新、終端60%以上が揃いD3化すれば○。出来高60%以上が望ましい | **△〜○** 後場VWAP上維持かつ終端60%以上なら小さく可。当日高値圏でなければ持ち越しは弱い |
| D3強 | **○** `VWAP-0.25ATR〜VWAP` または `支持線〜支持線+0.25ATR`。RR良好なら可 | **◎** `VWAP15分維持＋出来高80%以上`。小さく可。通常サイズは25日線奪回後 | **◎** 後場VWAP上維持なら持ち越し候補。25日線未満のためサイズは抑える |
| D3 | **○〜△** `支持線〜支持線+0.25ATR`。RR1.5未満なら見送り | **○** 小さく可。`VWAP〜VWAP+0.20ATR`。出来高増加または前日高値試しで信頼度を上げる | **○〜△** 後場VWAP上維持なら可。出来高不足またはN/Aなら持ち越しは慎重 |
| D3弱 | **△** 支持線近辺のみ。RR2.0以上で最小ロット | **△** 前日高値試しまたは終端70%以上なら小さく可 | **△〜×** 後場VWAP維持でも出来高が戻らなければ監視継続 |

D2のVWAP回復は、D3必須条件を満たさない段階ではD2のままであり、評価は△とする。
D3条件がすべて成立した時点でD3へ再分類し、○以上の評価を適用する。

### 8.10 指値帯とRR

- 指値帯はATR14と採用支持線またはVWAPから計算し、価格へ展開して表示する。
- RRのエントリー価格は、指値帯上限を使用して保守的に計算する。
- 損切り価格は `採用支持線 - 0.35ATR` とする。
- 目標価格は、25日線と現在値より上の直近抵抗線のうち、エントリー価格より上で最も近い価格とする。
- `RR = (目標価格 - エントリー価格) / (エントリー価格 - 損切り価格)` とする。
- ATR14、採用支持線、目標価格のいずれかが欠損する場合は `RR算出不可` と表示する。
- ATR14または採用支持線が欠損して指値帯を計算できない場合は `指値算出不可` と表示する。
- 「地合い良好」は当面は裁量条件とし、US Market指標からの自動判定には使用しない。

## 9. D2とD3の境界

| 項目 | D2 | D3 |
|---|---|---|
| VWAP | 未回復 | 回復済み |
| 価格構造 | 支持線反発の候補 | 安値切り上げ・高値更新を確認 |
| 行動 | まだ入らない | 小さく入れる候補 |
| 次の確認 | VWAP回復 | 25日線奪回 |
| 主なリスク | 支持線割れ、下落継続 | 戻り売り、VWAP再割れ |

## 10. 実装に必要な指標

| 指標 | 現状 | 対応案 |
|---|---|---|
| 25日線・ATR14・VWAP・終端位置・出来高比 | 取得済み | 既存値を使用 |
| 支持線・抵抗線候補 | 取得済み | 採用線と距離ATRを明示する |
| 安値切り上げ・高値更新 | 取得済み | 連続回数と成立回数を分ける |
| 3日連続安値切り下げ | 専用値なし | 直近3比較の連続フラグを追加する |
| VWAP上維持15分 | 現在のランク入力にはなし | 当日足から連続維持時間を計算する |
| 前日高値・直近抵抗線試し | 元データあり | 抵抗線までのATR距離を追加する |
| 出来高急増の陰線 | 判定関数あり | D2除外条件として明示利用する |
| 25日線乖離ラベル | 数値取得済み | 分類後にラベル化する |

## 11. VWAP15分維持の計算仕様

- 入力は当日の5分足とする。
- 各足までの累積VWAPを計算する。
- 各5分足の終値が、その足時点の累積VWAPを上回っているか判定する。
- 最新足から連続するVWAP上の確定足を数える。
- 3本以上連続、すなわち15分以上でD3のVWAP維持条件を成立とする。
- 形成中の未確定足は連続本数に含めない。
- 5分足の開始時刻から5分を経過した足を確定足とする。大引け後は当日最終足を確定足とする。
- 昼休みをまたぐ場合は連続時間をリセットする。
- 当日5分足が3本未満、欠損、または日足参考VWAPしかない場合はD3を `判定保留` とする。

## 12. D3不成立時のVWAP上銘柄

25日線未満かつVWAP上で、D3の価格構造条件またはVWAP15分維持条件を満たさない銘柄はD1とする。

- `25日線距離ATR <= 2.0`: D1a
- `25日線距離ATR > 2.0`: D1b
- ATR14または25日線距離が欠損: D1判定保留

したがって、必要値が取得できる限り「D3不成立かつD1でもないVWAP上銘柄」は発生しない。

## 13. 実装案

### 13.1 判定価格の一本化

ランキング判定へ渡す値をまとめた評価コンテキストを追加する。

```text
TechnicalRankingContext
  evaluation_price
  evaluation_price_source
  evaluation_timestamp
  session_state
  vwap
  vwap_maintained_minutes
  intraday_data_sufficient
```

`evaluation_price` は、場中なら `vwap_snapshot["latest"]`、大引け後なら
`snapshot.price.close` を採用する。ランキング、終端位置、支持線復帰、VWAP位置、
25日線距離ATRはすべて同じ `evaluation_price` から計算する。

### 13.2 VWAP15分維持

`app/domain/policies/market_history.py` の5分足VWAP計算に、次を追加する。

```text
vwap_maintained_bars
vwap_maintained_minutes
vwap_maintained_15m
```

当日の確定5分足ごとに累積VWAPを計算し、最新足から連続する
`Close > 累積VWAP` の本数を数える。3本以上で `vwap_maintained_15m=True` とする。

### 13.3 ランキング判定

`app/domain/policies/technical_summary.py` を次の責務に分ける。

1. 25日線未満かつVWAP上では、D3を先に判定する。
2. D3は価格構造条件に加え `vwap_maintained_15m is True` を必須とする。
3. D3不成立なら、ATR距離にかかわらずランキングはD1とする。
4. D1の詳細表示だけを `D1a` / `D1b` / `判定保留` に分ける。
5. D3成立後の出来高比はランキングに使わず、詳細表示の強弱だけに使う。
6. 25日線乖離率はD系分類から外し、分類後のリスクラベル生成に使う。

### 13.4 D2判定

D2では採用支持線を返す評価結果モデルを追加する。

```text
D2Evaluation
  established
  selected_support_label
  selected_support_price
  support_distance_atr
  exclusion_reason
```

これにより「支持線明確割れ」「直下支持線なし」を同じ採用支持線で判定し、
詳細画面にも除外理由を表示できる。

### 13.5 詳細表示モデル

ランキング本体の `TechnicalSummaryRank` はD1/D2/D3のまま維持し、
単一銘柄詳細用に次の表示属性を追加する。

```text
rank_detail_code: D1a | D1b | D3強 | D3 | D3弱 | 判定保留
rank_detail_text
ma25_distance_atr
dev25_risk_label
vwap_maintained_minutes
```

これによりランキング集計の互換性を保ちながら、詳細画面だけ細分化できる。

### 13.7 テスト方針

- 5分足3本連続VWAP上でD3、2本ではD1になること。
- 昼休みをまたぐVWAP上の足を連続扱いしないこと。
- 出来高比が80%以上、60%以上80%未満、60%未満でもすべてD3のままであること。
- D3詳細表示だけがD3強、D3、D3弱に変化すること。
- D1が2ATR境界でD1a/D1bに分かれること。
- D2が支持線明確割れ、直下1ATR以内の支持線なしで除外されること。
- 場中は5分足現在値、大引け後は日足終値で同じ銘柄を判定すること。
- 5分足不足時にD3を成立させず、判定保留理由を表示すること。
