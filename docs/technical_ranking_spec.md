# Technical ランキング・指標仕様

## 1. 目的

本書は Technical 分析に必要な指標計算、VWAP定義、ローソク足型判定、
ランキング分類条件を一元管理する。

ランキング分類、表示形式、現行実装状況については以下に一任する。

- ランキング分類条件の正本：本書

## 2. Technical 計算 / 日足ベースの指標

日足ベースで次を計算する。

| 指標 | 定義 |
|---|---|
| 5日移動平均 | 直近5営業日の終値の算術平均 |
| 5日線の傾き | `当日5日線 - 前日5日線`。0未満なら短期線低下 |
| 25日移動平均 | 直近25営業日の終値の算術平均 |
| 25日線からの乖離率 | `(現在値 - 25日線) / 25日線 * 100 %` |
| RSI14 | 14本の価格変動に対する上昇幅の割合。`100 * (平均上昇幅 / (平均上昇幅 + 平均下降幅))` |
| ATR14 | 14本の実現値幅の指数平滑移動平均。TR = `max(高値 - 安値, 高値 - 前日終値, 前日終値 - 安値)` |
| 当日値幅とATR比 | `当日値幅 / ATR14` |
| 当日終端位置 | `(現在値 - 当日安値) / (当日高値 - 当日安値) * 100` |
| 前日高値更新 | `当日高値 > 前日高値` |
| 前日安値維持 | `当日安値 >= 前日安値` |
| 前日出来高20日平均比 | `当日出来高 / 20日平均出来高 * 100` |
| 5日/20日/60日の高値/安値 | 直近N営業日の高値の最大値、安値の最小値 |

## 3. VWAP関連指標

### 3.1 日中VWAP（場中の短期移動平均代わり）

日中VWAPは、5分足が取得できる場合は5分足から計算する。

**計算式：**
```
VWAP = Σ(5分足の(高値+安値+終値)/3 × 出来高) / Σ(5分足の出来高)
```

取得できない場合は日足の参考値 `(当日高値 + 当日安値 + 当日終値) / 3` を日中VWAP代替値として使う。

### 3.2 前日全体VWAP・前場VWAP・後場VWAP

前日5分足から以下を計算する。

| 指標 | 定義 |
|---|---|
| 前日全体VWAP | 前日全営業時間の全5分足から計算したVWAP |
| 前日前場VWAP | 前日前場（09:00～11:30）の5分足から計算したVWAP |
| 前日後場VWAP | 前日後場（12:30～15:00）の5分足から計算したVWAP |
| 前場VWAP維持 | 現在値が前日前場VWAPより上 |
| 後場VWAP維持 | 現在値が前日後場VWAPより上 |
| 前日終値の後場VWAP位置 | `前日終値 > 前日後場VWAP` の場合 `後場上抜け`、そうでなければ `後場VWAP下` |

### 3.3 VWAP位置判定

| 判定 | 条件 |
|---|---|
| VWAP上 | `現在値 > VWAP` |
| VWAP接近 | `VWAP - 0.2ATR14 <= 現在値 <= VWAP` |
| VWAP以下 | `現在値 <= VWAP` |

### 3.4 VWAP距離ATR

```
VWAP距離ATR = (VWAP - 現在値) / ATR14
```

VWAP上にいる場合は負値となり、VWAP下にいる場合は正値となる。

### 3.5 VWAP維持時間

直近のVWAP上抜け後、連続してVWAP上にいる時間（分単位）。

## 4. ローソク足型と髭（ひげ）

### 4.1 ローソク足型判定

前日の日足OHLCから判定する。

| 条件 | ラベル |
|---|---|
| `range <= 0` または欠損 | `N/A` |
| 実体比 < 10% または `始値 == 終値` | `十字` |
| 実体比 < 30% | `小陽線` / `小陰線` |
| 実体比 < 65% | `陽線` / `陰線` |
| それ以外 | `大陽線` / `大陰線` |

**実体比の定義：**
- 陽線の場合：`(終値 - 始値) / (高値 - 安値) * 100`
- 陰線の場合：`(始値 - 終値) / (高値 - 安値) * 100`

**range の定義：**`高値 - 安値`

### 4.2 髭（ひげ）判定

ローソク足の上下の髭を判定する。

| ヒゲ種別 | 条件 |
|---|---|
| 上髭 | 上ヒゲ比率 >= 30% かつ 実体の1.5倍以上 かつ 下ヒゲより長い |
| 下髭 | 下ヒゲ比率 >= 30% かつ 実体の1.5倍以上 かつ 上ヒゲより長い |
| ヒゲなし | 上記いずれでもない |
| N/A | `range <= 0` または欠損 |

**ヒゲ比率の定義：**

```
上ヒゲ比率 = (高値 - max(始値, 終値)) / (高値 - 安値) * 100
下ヒゲ比率 = (min(始値, 終値) - 安値) / (高値 - 安値) * 100
```

**実体の定義：**
```
実体 = abs(終値 - 始値)
```

## 5. 共通指標定義

### 5.1 基本指標

| 指標 | 定義 |
|---|---|
| 25日線位置 | `現在値 < 25日線` をD系判定の前提とする |
| 終端位置 | `(現在値 - 当日安値) / (当日高値 - 当日安値) * 100` |
| 25日線距離ATR | `(25日線 - 現在値) / ATR14`。25日線未満で正値となる |
| 支持線距離ATR | `abs(当日安値 - 支持線) / ATR14` |
| 出来高比 | `当日出来高 / 20日平均出来高 * 100` |

### 5.2 判定価格と評価コンテキスト

- **通常取引の場中：** 当日最新5分足の終値を現在値として使う
- **大引け後：** 確定した当日の日足終値を使う
- **大引け直後（終値未取得）：** 当日最終5分足の終値を暫定終値として使う
- **場中の休場時間（11:30～12:30）：** 当日最新5分足の現在値を使う
- **休日・当日足がない場合：** 直近取引日の終値を使い、過去日データであることを表示

判定価格、判定時刻、価格ソースを同じ評価コンテキストに保持する。

### 5.3 ATR14 欠損時の方針

- ATR14 が0または欠損の場合、ATRを使う必須条件は `判定保留` とする
- ATRを参照する指標（例：距離計算、RR計算）も合わせて `N/A` または `算出不可` とする

## 6. 陽線・陰線・上値失速の定義

### 6.1 陽線・陰線

| 種別 | 条件 |
|---|---|
| 陽線 | `終値 > 始値` |
| 陰線 | `終値 < 始値` |
| 実体条件付き陰線 | 陰線 かつ 実体が `0.15ATR` 以上 |

### 6.2 上値失速

```
上ヒゲが当日値幅の45%以上、かつ実体の1.5倍以上
```

定義式：
```
上ヒゲ比率 >= 45% かつ 上ヒゲ >= 実体 * 1.5
```

## 7. Technical Summary ランキング分類

### 7.1 基本方針

- 25日線の上下と VWAP の上下を、D系ランクの主要な状態判定に使う
- 25日線乖離率は D1 / D2 / D3 の必須条件にしない
- 25日線乖離率は、反発余地、25日線奪回難易度、戻り売りリスクを示す補助ラベルに使う
- D2 は「まだ入らない候補」、D3 は「小さく入れる候補」とする
- 25日線未満かつVWAP上でD3を満たさない銘柄は、25日線距離ATRにより D1a / D1b へ分類する
- 必須データが欠損した場合は、成立扱いにせず `判定保留` とする
- 全ランキングで、場中は現在値、大引け後は当日終値を判定価格に使う

### 7.2 全ランク一覧

| ランク | 表示名 | 分類の中心 |
|---|---|---|
| A1 | 位置良好 | 25日線上、VWAP上、過熱なし |
| A2 | 上昇継続 | 25日線上、VWAP上、4〜7%の上昇継続 |
| B1 | 上昇後半 | 25日線上、乖離7%以上、かつ3日騰落・60日レンジ位置・VWAPのいずれかが強い |
| B2 | 過熱極大 | 25日線から極端に上方乖離 |
| C1 | 押し目候補 | 25日線上、VWAP下または接近 |
| C2 | 崩れ警戒 | 25日線上だが価格構造が悪化 |
| D1 | 戻り途中 | 25日線下、VWAP上、反転未確認 |
| D2 | 底打ち候補 | 25日線下、VWAP以下、支持線反発候補 |
| D3 | 底打ち初動 | 25日線下、VWAP回復、反転確認 |
| E | 下落トレンド | 25日線下でD1/D2/D3不成立 |

注: 現行実装では B2 は `25日線乖離率 >= 10%` または `25日線距離ATR >= 2.0` で判定する。RSI高位、3日騰落率高位は実装途中の補助条件として扱い、現時点では B2 判定条件に含めない。出来高比150%以上も B2 判定条件に含めない。

### 7.3 25日線乖離率による位置説明・行動補助

25日線乖離率は、現行ランク分類を置き換えず、位置説明と行動補助に使う。
実際のランクは VWAP位置、3日騰落、60日レンジ位置、D系の反転条件も含めて判定する。

| 25日線乖離率 | 位置説明 | 行動補助 |
|---:|---|---|
| 25日線下 | `25日線下・奪回待ち` | 原則監視。D3成立時のみ小さく可 |
| 0〜4% | `安全寄り・値幅不足` | VWAP上なら候補、VWAP下なら回復待ち |
| 4〜7% | `上昇継続・追いかけ注意` | 支持線待ち、小さく検討 |
| 7〜10% | `上昇後半・深追い注意` | 新規慎重、押し待ち |
| 10%以上 | `過熱極大・利確優先` | 新規買い非推奨、利確優先 |

### 7.4 D系ランクの判定順

現在値が25日線未満の場合、次の順で判定する。

1. VWAP上なら D3 を判定する
2. D3不成立なら、25日線距離ATRにより D1a / D1b を判定する
3. VWAP以下なら D2 を判定する
4. D1 / D2 / D3 のいずれにも該当しない場合は E とする

## 8. D1 戻り途中 / 25日線奪回待ち

### 8.1 位置づけ

VWAPは回復したが、反転確認は不十分で、25日線が上値抵抗になっている状態。
新規買いを急がず、25日線奪回または上値の確認を待つ。

### 8.2 必須条件

- 現在値が25日線未満
- 現在値がVWAPより上
- D3条件を満たさない

### 8.3 詳細画面のD1サブ分類

D1a / D1b はランキングコードを増やさず、単一銘柄詳細画面だけのサブ分類とする。

| サブ分類 | 条件 | 表示名 | 意味 |
|---|---|---|---|
| D1a | `25日線距離ATR <= 2.0` | `戻り途中・25日線接近` | 25日線奪回を試せる距離だが、利確圧力に注意 |
| D1b | `25日線距離ATR > 2.0` | `戻り途中・25日線遠い` | 25日線奪回まで値幅があり、戻り確認を継続 |

ATR14または25日線が欠損する場合もランキングはD1とし、詳細サブ分類だけを `D1 判定保留` とする。

### 8.4 表示文

状態に応じて次を組み合わせる。

- `戻り途中`
- `25日線奪回待ち`
- `上値確認中`
- `25日線接近なら利確圧注意`
- `25日線まで距離あり`

### 8.5 売買行動

- 基本は監視継続
- 25日線接近時は利確圧力を警戒する
- 追加買いは25日線奪回後を基本とする
- D1bはD1aよりも25日線奪回までの不確実性が高いため、監視継続を優先する

## 9. D2 底打ち候補 / 支持線反発待ち

### 9.1 位置づけ

支持線付近で反発の兆候はあるが、VWAPを回復していない状態。
D2は「まだ入らない候補」とし、新規買いは待つ。

### 9.2 必須条件

- 現在値が25日線未満
- 現在値がVWAP以下
- いずれかの支持線について `abs(当日安値 - 支持線) <= 0.35 * ATR14`
- 終値または現在値が、採用した支持線より上へ戻っている
- `VWAP - 1.0 * ATR14 <= 現在値 <= VWAP`
- 除外条件に該当しない

支持線候補は、前日安値、20日安値、75日線、60日安値とする。
25日線は上値抵抗として扱い、D2の支持線候補には含めない。

### 9.3 除外条件

推奨する数値定義は次の通り。

| 除外条件 | 推奨初期値 |
|---|---|
| 支持線明確割れ | `当日安値 < 支持線 - 0.35 * ATR14` かつ `判定価格 < 支持線` |
| 3日連続安値切り下げ | 直近3比較の `当日安値 < 前日安値` がすべて成立 |
| 出来高急増の陰線 | 出来高比180%以上、陰線、実体が当日レンジの65%以上 |
| 直下支持線なし | 判定価格より下、かつ1.0ATR以内に支持線候補がない |
| 終端位置が40%未満 | 終端位置 < 40% |

- 支持線を明確に割れている
- 終端位置が40%未満
- 3日連続で安値を切り下げている
- 出来高急増を伴う陰線
- 現在値の直下に有効な支持線がない

### 9.4 25日線乖離ラベル

25日線乖離率は分類条件ではなく、リスク表示に使う。

| 25日線乖離率 | ラベル |
|---|---|
| `-3%以上 0%未満` | 浅押し反発候補 |
| `-8%以上 -3%未満` | 浅押し反発候補 |
| `-15%以上 -8%未満` | 底打ち候補 |
| `-15%未満` | 深掘れ反発候補・リスク大 |

### 9.5 表示文と売買行動

- 表示名: `底打ち候補`
- 状態: `支持線反発待ち`
- 行動: `まだ入らない`
- 次確認: `VWAP回復待ち`
- リスク: 25日線乖離ラベルを併記する

## 10. D3 底打ち初動 / 反転確認

### 10.1 位置づけ

VWAPを回復し、価格モメンタムと終端位置から反転初動を確認できる状態。
D3は「小さく入れる候補」とし、通常サイズのエントリーとは区別する。

### 10.2 必須条件

- 現在値が25日線未満
- 現在値がVWAPより上
- 安値切り上げが2回以上
- 高値更新が1回以上
- 終端位置が60%以上
- VWAP上を15分以上連続維持している

出来高比はD3分類の必須条件にしない。単一銘柄詳細画面のD3強弱表示にのみ使う。

### 10.3 推奨追加条件

- 現在値が前日高値または直近抵抗線を試している
- `25日線距離ATR <= 2.0`

推奨追加条件はD3の必須条件にはせず、信頼度または表示ラベルに使う。

### 10.4 25日線乖離ラベル

| 25日線乖離率 | ラベル |
|---|---|
| `-4%以上 0%未満` | 25日線奪回接近 |
| `-8%以上 -4%未満` | 反転初動 |
| `-15%以上 -8%未満` | 深押し反転 |
| `-15%未満` | 急落リバ・戻り売り警戒 |

### 10.5 表示文

成立した条件とリスクに応じて次を組み合わせる。

- `底打ち初動`
- `VWAP回復`
- `安値切り上げ`
- `反転確認`
- `25日線奪回待ち`
- `戻り売り注意`

### 10.6 単一銘柄詳細画面のD3強弱

D3成立後、出来高比によって詳細画面の表示を3段階に分ける。
この強弱はD3ランキング分類を変更しない。

| 詳細表示 | 出来高比 | 表示文 |
|---|---:|---|
| D3強 | 80%以上 | `D3強｜VWAP維持・出来高伴う` |
| D3 | 60%以上80%未満 | `D3｜VWAP維持・出来高やや不足` |
| D3弱 | 60%未満 | `D3弱｜反転形あるも出来高不足` |

出来高比が欠損する場合は `D3｜VWAP維持・出来高N/A` とする。

### 10.7 売買行動

- 小さな試し玉のみ候補とする
- 25日線奪回前は通常サイズへ増やさない
- 乖離が大きい場合は、戻り売りリスクを表示してサイズを抑える
- VWAP割れ、安値切り下げ、支持線割れのいずれかで前提崩れとする

### 10.8 D系詳細分類

D系の D1a / D1b / D3強 / D3弱 などの詳細分類は、戦略判定や補助判断の材料として残す。単一銘柄Technical出力の冒頭短評は詳細分類文言ではなく、25日線位置、出来高コメント、崩れ警戒スコアを使って統一表示する。

| 詳細分類 | 主判定 |
|---|---|
| D1a | `監視優先。D3化なら小さく可` |
| D1b | `監視優先。深指値は原則不可` |
| D1判定保留 | `判定保留。新規不可` |
| D2 | `支持線反発候補。原則VWAP回復待ち` |
| D3強 | `小さく可。D3内で最有力` |
| D3 | `小さく可。出来高確認` |
| D3弱 | `監視寄り。出来高不足` |

冒頭短評の表示例:
```
短評：25日線下・奪回接近｜出来高伴う｜崩れ 2/9：軽度崩れ
短評：25日線下・奪回待ち｜出来高やや薄い｜崩れ 4/9：崩れ警戒
```

### 10.9 D系詳細戦略判定

戦略判定は、表示時点で売買シグナルが成立したことを示すものではない。
「深押し指値」「前場VWAP回復」「後場VWAP回復」の各シナリオが成立した場合の
行動指針を並べる。前場・後場の区分は取得した5分足の時刻を使用する。

| 短評 | 深押し指値 | 前場VWAP回復 | 後場VWAP回復 |
|---|---|---|---|
| D1a 戻り途中・25日線接近 | **△** 地合い良好なら `支持線〜支持線+0.15ATR`。RRは25日線または直近抵抗線までで判定。安全重視ならVWAP再回復確認 | **△** VWAP回復だけでは不可。`VWAP15分維持＋安値切り上げ＋高値更新` でD3化なら小さく可 | **△** 後場VWAP上維持なら小さく可。25日線接近時は利確圧に注意し、持ち越しは25日線手前で評価 |
| D1b 戻り途中・25日線遠い | **×〜△** 基本は危険。支持線が明確でRR2.0以上なら最小ロットのみ | **△** VWAP上でもD3未達なら監視。入るならD3条件成立後 | **△〜×** 出来高60%以上かつ終端60%以上がなければ見送り |
| D1 判定保留 | **×** ATR距離不明なら `指値算出不可` | **△** D3条件を満たせば小さく可。ただし通常サイズ不可 | **△〜×** 判定材料不足のため原則見送り |
| D2 底打ち候補 | **△** `支持線〜支持線+0.15ATR`。地合い良好時のみ。RR1.5以上なら試し可 | **△** VWAP15分維持なら試し玉候補。安値切り上げ、高値更新、終端60%以上が揃いD3化すれば○。出来高60%以上が望ましい | **△〜○** 後場VWAP上維持かつ終端60%以上なら小さく可。当日高値圏でなければ持ち越しは弱い |
| D3強 | **○** `VWAP-0.25ATR〜VWAP` または `支持線〜支持線+0.25ATR`。RR良好なら可 | **◎** `VWAP15分維持＋出来高80%以上`。小さく可。通常サイズは25日線奪回後 | **◎** 後場VWAP上維持なら持ち越し候補。25日線未満のためサイズは抑える |
| D3 | **○〜△** `支持線〜支持線+0.25ATR`。RR1.5未満なら見送り | **○** 小さく可。`VWAP〜VWAP+0.20ATR`。出来高増加または前日高値試しで信頼度を上げる | **○〜△** 後場VWAP上維持なら可。出来高不足またはN/Aなら持ち越しは慎重 |
| D3弱 | **△** 支持線近辺のみ。RR2.0以上で最小ロット | **△** 前日高値試しまたは終端70%以上なら小さく可 | **△〜×** 後場VWAP維持でも出来高が戻らなければ監視継続 |

D2のVWAP回復は、D3必須条件を満たさない段階ではD2のままであり、評価は△とする。
D3条件がすべて成立した時点でD3へ再分類し、○以上の評価を適用する。

### 10.10 指値帯とRR

- 指値帯はATR14と採用支持線またはVWAPから計算し、価格へ展開して表示する
- RRのエントリー価格は、指値帯上限を使用して保守的に計算する
- 損切り価格は `採用支持線 - 0.35ATR` とする
- 目標価格は、25日線と現在値より上の直近抵抗線のうち、エントリー価格より上で最も近い価格とする
- `RR = (目標価格 - エントリー価格) / (エントリー価格 - 損切り価格)` とする
- ATR14、採用支持線、目標価格のいずれかが欠損する場合は `RR算出不可` と表示する
- ATR14または採用支持線が欠損して指値帯を計算できない場合は `指値算出不可` と表示する
- 「地合い良好」は当面は裁量条件とし、US Market指標からの自動判定には使用しない

## 12. 単一銘柄Technical出力の崩れ警戒スコア

単一銘柄Technical出力では、25日線の上下にかかわらず崩れ警戒を表示する。
次の条件を各1点として合計する。値が欠損して条件を評価できない場合は加点しない。

| 条件 | 点数 |
|---|---:|
| 現在値が25日線未満 | +1 |
| 現在値がVWAP未満 | +1 |
| 直近3営業日の安値切り上げがすべて不成立 | +1 |
| 直近3営業日の高値更新がすべて不成立 | +1 |
| 終端位置が40%未満 | +1 |
| 出来高20日平均比が100%超、かつ陰線または上値失速 | +1 |
| 直下支持線までの距離が0.7ATR超 | +1 |
| 25日線の傾きが低下（5日前の25日線より低い） | +1 |
| 5日線の傾きが低下（前日の5日線より低い） | +1 |

**定義補足：**

- **陰線：** `終値 < 始値` かつ実体が `0.15ATR` 以上
- **上値失速：** 上ヒゲが当日値幅の45%以上、かつ実体の1.5倍以上
- **直下支持線：** 現在値より下にある25日線、前日安値、20日安値、75日線、60日安値のうち最も近い価格
  - 候補がない場合、またはATRを取得できない場合は距離条件を加点しない

### 12.1 崩れスコアのランク別ラベル表示

表示は `崩れ {score}/9：{ラベル}` 形式とする。

| ランク | 0〜2点 | 3〜4点 | 5〜6点 | 7〜9点 |
|---|---|---|---|---|
| A*, B*, D2, D3, E | 崩れ軽微 | 上値重い | 崩れ警戒 | 買い不可 |
| C1 | 押し目候補 | VWAP回復待ち | 押し目ではなく崩れ警戒 | 買い不可 |
| C2 | 軽度崩れ | 崩れ警戒 | 買い不可 | 買い不可 |
| D1 | 戻り良好 | 25日線奪回待ち | 戻り売り警戒 | 買い不可 |

表示例: `崩れ 5/9：崩れ警戒`

## 13. 底打ち初動・ホールド判定

### 13.1 底打ち初動判定

底打ち初動判定は現在値が25日線未満の場合だけ表示し、
Technical Summaryランクが `D3` の場合を `成立`、それ以外を `未成立` とする。

### 13.2 ホールド判定

ホールド判定は次の条件を使う。25日線近接および支持線が近い状態は `0.7ATR以内` とする。
条件が重複する場合は `×`、`△`、`◎`、`○` の順に優先し、
どの条件にも完全一致しない場合は `△` とする。

| 判定 | 条件 |
|---|---|
| ◎ | 25日線以上、VWAP以上、終端位置50%以上、出来高20日平均比80%以上、直下支持線まで0.7ATR以内 |
| ○ | 25日線以上または25日線まで0.7ATR以内、VWAP以上、直近3営業日に安値切り上げが1つ以上 |
| △ | VWAP以上だが25日線未満、または終端位置50%未満、または出来高20日平均比80%未満 |
| × | VWAP未満、25日線未満、直近3営業日の安値切り上げがすべて不成立、直下支持線まで0.7ATR超をすべて満たす |

## 14. US Market Technical Summary

Technical Summary の冒頭には US Market セクションを表示する。

対象は以下の通り。

- `NASDAQ総合`
- `SOX指数`
- `NVIDIA`
- `GRID`
- `日経先物`
- `銅先物(COMEX)`
- `WTI原油`

各行は yFinance の日足から以下を計算する。

| 指標 | 計算 |
|---|---|
| 直近値 | 当日終値 |
| 前日騰落 | 当日終値 - 前日終値 |
| 5日移動平均乖離 | 25日線乖離率と同じ方式で計算 |
| 25日移動平均乖離 | (現在値 - 25日線) / 25日線 * 100 |
| RSI14 | 14本ベースで計算 |

US Market の取得失敗は Technical Summary 全体の失敗にしない。
取得できない指標は skipped として理由を保持し、表示可能な指標だけを出力する。
