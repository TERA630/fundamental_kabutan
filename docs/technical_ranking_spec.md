# Technical ランキング・指標仕様

## 1. 目的

本書は Technical 分析に必要な指標計算、VWAP定義、ローソク足型判定、ランキング分類条件を一元管理する。
ランキング分類は、単一銘柄 Technical 出力と監視銘柄 Technical Summary で共通とする。

- 画面・表示仕様：`docs/screen_spec.md`
- 現行実装状況：`docs/current_implementation_spec.md`

## 2. Technical 計算 / 日足ベースの指標

日足ベースで次を計算する。

| 指標 | 定義 |
|---|---|
| 5日移動平均 | 直近5営業日の終値の算術平均 |
| 5日線の傾き | 当日5日線 - 前日5日線 |
| 前日5日線の傾き | 前日5日線 - 2営業日前5日線 |
| 3営業日前5日線の傾き | 3営業日前5日線 - 4営業日前5日線 |
| 25日移動平均 | 直近25営業日の終値の算術平均 |
| 5営業日前25日線 | 5営業日前時点の25日移動平均。25日線の向き判定に使う |
| 25日線からの乖離率 | `(現在値 - 25日線) / 25日線 * 100 %` |
| RSI14 | 14本の価格変動に対する上昇幅の割合。`100 * (平均上昇幅 / (平均上昇幅 + 平均下降幅))` |
| ATR14 | 14本の実現値幅の指数平滑移動平均。TR = `max(高値 - 安値, 高値 - 前日終値, 前日終値 - 安値)` |
| 当日値幅とATR比 | `当日値幅 / ATR14` |
| 当日終端位置 | `(現在値 - 当日安値) / (当日高値 - 当日安値) * 100` |
| 前日高値更新 | `当日高値 > 前日高値` |
| 前日安値切り上げ | `当日安値 >= 前日安値` |
| 前日出来高20日平均比 | `当日出来高 / 20日平均出来高 * 100` |
| 5日/20日/60日の高値/安値 | 直近N営業日の高値の最大値、安値の最小値 |

## 3. VWAP関連指標

### 3.1 日中VWAP（場中の短期移動平均代わり）

日中VWAPは、5分足が取得できる場合はそれから計算する。

**計算式：**
```
VWAP = Σ(5分足の(高値+安値+終値)/3 × 出来高) / Σ(5分足の出来高)
```

取得できない場合は日足の参考値 `(当日高値 + 当日安値 + 当日終値) / 3` を日中VWAP代替値として使う。

### 3.2 前日全体VWAP・前場VWAP・後場VWAP

前日5分足から以下を計算する。

| 指標 | 定義 |
|---|---|
| 前日全体VWAP | 前日全営業時間の全5分足から計算したVWAP |
| 前日前場VWAP | 前日前場（09:00～11:30）の5分足から計算したVWAP |
| 前日後場VWAP | 前日後場（12:30～15:00）の5分足から計算したVWAP |
| 前場VWAP維持 | 前日前場の最終5分足終値が前日前場VWAP以上 |
| 後場VWAP維持 | 前日終値が前日後場VWAP以上 |
| 前日終値の後場VWAP位置 | `前日終値 > 前日後場VWAP` の場合 `上`、それ以外は `下` |

### 3.3 VWAP位置判定

| 判定 | 条件 |
|---|---|
| VWAP上 | `現在値 > VWAP` |
| VWAP接近 | `VWAP - 0.2ATR14 <= 現在値 <= VWAP` |
| VWAP以下 | `現在値 <= VWAP` |
| VWAP明確われ|　`現在値 <= VWAP－0.35× ATR14` |

### 3.4 VWAP維持時間

直近のVWAP上抜け後、連続してVWAP上にいる時間（分単位）。
現行実装では、確定済み5分足だけを対象に、直近セッション内で終値がVWAPを上回った連続本数を数える。前場は09:00以降、後場は12:30以降を別セッションとして扱い、昼休みをまたいだ維持本数は引き継がない。連続本数 `3本以上` を 
`VWAP15分維持` とする。

## 4. ローソク足型と髭（ひげ）

### 4.1 陽線・陰線

| 種別 | 条件 |
|---|---|
| 陽線 | `終値 > 始値` |
| 陰線 | `終値 < 始値` |
| 実体条件付き陰線 | 陰線 かつ 実体が `0.15ATR` 以上 |

### 4.2 ローソク足型判定

前日の日足OHLCから判定。

**range = 高値 - 安値**

**実体比：**
- 陽線：`(終値 - 始値) / range * 100`
- 陰線：`(始値 - 終値) / range * 100`

| 条件 | ラベル |
|---|---|
| `range <= 0` または欠損 | `N/A` |
| 実体比 < 10% または 始値=終値 | `十字` |
| 実体比 < 30% | `小陽線` / `小陰線` |
| 実体比 < 65% | `陽線` / `陰線` |
| それ以外 | `大陽線` / `大陰線` |

### 4.3 髭（ひげ）判定

**実体 = `abs(終値 - 始値)`**

**ヒゲ比率：**
```
上ヒゲ比率 = (高値 - max(始値, 終値)) / range * 100
下ヒゲ比率 = (min(始値, 終値) - 安値) / range * 100
```

| ヒゲ種別 | 条件 |
|---|---|
| 上髭 | 上ヒゲ比率 >= 30% かつ 実体の1.5倍以上 かつ 下ヒゲより長い |
| 下髭 | 下ヒゲ比率 >= 30% かつ 実体の1.5倍以上 かつ 上ヒゲより長い |
| ヒゲなし | 上記いずれでもない |
| N/A | `range <= 0` または欠損 |

## 5. 共通指標定義

### 5.1 基本指標

| 指標 | 定義 |
|---|---|
| 25日線位置 | `現在値 < 25日線` を反転補助状態判定の前提とする |
| 終端位置 | `(現在値 - 当日安値) / (当日高値 - 当日安値) * 100` |
| 25日線距離ATR | `(現在値 - 25日線) / ATR14`　|
| 25日線奪回距離ATR | `abs(現在値 - 25日線) / ATR14`。D1a / D1b の25日線接近判定用　|
| 支持線距離ATR | `abs(当日安値 - 支持線) / ATR14` |
| 出来高比 | `当日出来高 / 20日平均出来高 * 100` |

### 5.2 判定価格と評価コンテキスト

- **日足と同じ日付の5分足があり、最新5分足が15:25より前：** 最新5分足の終値を現在値として使う
- **日足と同じ日付の5分足があり、最新5分足が15:25以降：** 確定した日足終値を使う
- **日足より新しい日付の5分足があり、最新5分足が15:25より前：** 最新5分足の終値を現在値として使う
- **日足より新しい日付の5分足があり、最新5分足が15:25以降：** 最新5分足の終値を暫定終値として使う
- **5分足がない、または同一/新規日付として使えない場合：** 日足終値を使う

判定価格、判定時刻、価格ソースを同じ評価コンテキストに保持する。現行実装では、昼休みや休日を別条件として分岐せず、利用可能な5分足の日付と最新時刻で評価価格を決める。

### 5.3 ATR14 欠損時の方針

- ATR14 が0または欠損の場合、ATRを使う必須条件は `判定保留` とする
- ATRを参照する指標（例：距離計算、RR計算）も合わせて `N/A` または `算出不可` とする

## 6. 上値失速の定義

```
上ヒゲが当日値幅の45%以上、かつ実体の1.5倍以上
```
定義式：
```
上ヒゲ比率 >= 45% かつ 上ヒゲ >= 実体 * 1.5
```

## 7. Technical Summary ランキング分類

### 7.1 基本方針

- Technicalランクは最新1年バックテストの25日線乖離率帯を表す位置ランクとする
- 1Y位置評価は位置ランクと同じ境界から新規エントリー推奨を返す
- 崩れ状態と反転状態は位置ランクを変更せず、独立した補助状態として保持する
- 利用者向け表示は原則として `{位置ランク} {状態表示名}｜{補助状態}｜{1Y位置評価}` とする
- 25日線未満のVWAP回復、支持線反発、反転確認条件は反転補助状態として評価する
- D1a / D1b、D2弱、D3強 / D3 / D3弱は戦略判定用の詳細分類として維持する
- 必須データが欠損した場合は、成立扱いにせず `判定保留` とする
- 全ランキングで、場中は現在値、大引け後は当日終値を判定価格に使う
- `Focus_theme`、銘柄名キーワード、テーマ性はランキング分類条件に使わない

### 7.2 A / B / C 系の補助条件

#### 7.2.1 高乖離帯の他指標過熱兆候

`25日線乖離率 8%以上10%未満` では、次のいずれかを満たす場合を過熱兆候ありとする。

| 条件 | 判定 |
|---|---|
| 3日騰落率 | `3日騰落率 > 6%` |
| 60日レンジ位置 | `60日レンジ位置 >= 80%` |
| RSI14 | `RSI14 >= 70` |

過熱兆候の有無にかかわらずランクは A2 を維持する。終端位置は過熱条件および1Y位置評価へ使わない。過熱兆候がある場合は位置帯表示へ `（他指標過熱）` を付ける。

#### 7.2.2 崩れ条件（簡略版）

25日線乖離率が0%以上の銘柄は、位置ランク決定後に `12. 単一銘柄Technical出力の崩れ警戒スコア` を使って崩れ状態を判定する。崩れ警戒が成立しても位置ランクは変更しない。B1 / B2を含む全ての0%以上の位置ランクへ同じ判定を適用し、重大な崩れ条件成立時は1Y位置評価だけを `監視のみ` へ上書きする。

崩れ状態ラベルは次の通りとする。

| 条件 | ラベル | 位置ランク・行動への影響 |
|---|---|---|
| 重大な崩れ条件成立 | 崩れ警戒 | 位置ランク維持、1Y位置評価を監視のみに変更 |
| 崩れスコア2〜3点、かつ重大条件不成立 | 軽度警戒 | 位置ランク維持 |
| 崩れスコア1点 | 要確認 | ベースランク維持 |
| 崩れスコア0点 | 崩れ条件なし | ベースランク維持 |

上から順に評価し、最初に一致した行を採用する。

### 7.3.1 全ランク一覧

| ランク | 表示名 | 条件 | 行動 |
|---|---|---|---|
| B2 | 極端過熱 | `25日線乖離率 >= 12%` | 新規買い見送り・利確優先 |

### 7.3.3 1年バックテスト位置評価

1Y位置評価は位置ランクと同じ25日線乖離率帯から新規エントリーの推奨行動を返す。終端位置による分岐は行わない。

| 25日線乖離率 | 状態表示名 | 観測結果 | 1Y位置評価 |
|---:|---|---|---|
| 12%以上 | 極端過熱 | 極端過熱 | 新規買い見送り・利確優先 |
| 10%以上12%未満 | 過熱後半 | 過熱後半 | 過熱後半｜新規買い見送り |
| 8%以上10%未満 | 過熱選別 | 過熱帯 | 過熱帯｜追いかけ禁止 |
| 4%以上8%未満 | 上方乖離 | 中央値マイナス | 中央値マイナス｜押し目確認 |
| 0%以上4%未満 | 位置良好 | 位置良好 | 位置良好｜エントリー優先帯 |
| -2%以上0%未満 | 奪回待ち | 25日線直下 | 25日線奪回確認まで見送り |
| -4%以上-2%未満 | 反転初動候補・検証不足 | 件数不足 | 件数不足｜25日線奪回待ち |

境界値は下限側を含める。重大な崩れ条件成立時は位置ランクを維持し、1Y位置評価を `監視のみ` で上書きする。

### 7.4 反転補助状態の判定順

現在値が25日線未満の場合、位置ランクとは別に次の順で反転補助状態を判定する。

1. VWAP上なら反転確認条件を判定し、成立なら `反転確認` とする
2. VWAP上で反転確認不成立なら `VWAP回復・確認不足` とする
3. VWAP以下で支持線反発条件が成立すれば `支持線反発候補` とする
4. いずれにも該当しない場合は `反転未確認` とする

旧D1 / D2 / D3 / Eコードは位置ランクに使わない。D1a / D1b、D2弱、D3強 / D3 / D3弱の名称は詳細戦略判定用として残す。

## 8. VWAP回復・確認不足 / 旧D1詳細判定

### 8.1 位置づけ

VWAPは回復したが、反転確認は不十分で、25日線が上値抵抗になっている状態。
新規買いを急がず、25日線奪回または上値の確認を待つ。

### 8.2 詳細画面のD1サブ分類

D1a / D1b は位置ランクを変更せず、単一銘柄詳細画面と戦略判定だけのサブ分類とする。

| サブ分類 | 条件 | 表示名 | 意味 |
|---|---|---|---|
| D1a | `25日線奪回距離ATR <= 2.0` | `戻り途中・25日線接近` | 25日線奪回を試せる距離だが、利確圧力に注意 |
| D1b | `25日線奪回距離ATR > 2.0` | `戻り途中・25日線遠い` | 25日線奪回まで値幅があり、戻り確認を継続 |

ATR14または25日線が欠損する場合、位置ランクは乖離率帯のままとし、詳細サブ分類だけを `D1 判定保留` とする。

### 8.4 表示文

状態に応じて次を組み合わせる。

- `戻り途中`
- `25日線奪回待ち`
- `上値確認中`
- `25日線接近なら利確圧注意`
- `25日線まで距離あり`

### 8.5 売買行動

- 基本は監視継続
- 25日線接近時は利確圧力を警戒する
- 追加買いは25日線奪回後を基本とする
- D1bはD1aよりも25日線奪回までの不確実性が高いため、監視継続を優先する

## 9. 支持線反発候補 / 旧D2詳細判定

### 9.1 位置づけ

支持線付近で反発の兆候はあるが、VWAPを回復していない状態。
　

### 9.2 必須条件

- 現在値が25日線未満
- 現在値がVWAP以下
- いずれかの支持線について `abs(当日安値 - 支持線) <= 0.35 * ATR14`
- 終値または現在値が、採用した支持線から `+0.1 * ATR14` 以上戻っている
- `VWAP - 1.0 * ATR14 <= 現在値 <= VWAP`
- 除外条件に該当しない

支持線候補は、前日安値、20日安値、75日線、60日安値とする。
25日線は上値抵抗として扱い、D2の支持線候補には含めない。

前日安値単独を支持線として採用する場合は `D2弱` とする。`D2弱` は位置ランクを変更せず、単一銘柄詳細の補助表示だけで区別する。
ただし、前日安値が20日安値、60日安値、75日線のいずれかと `0.35 * ATR14` 以内に近接している場合は、通常の支持線として扱う。

### 9.3 除外条件

推奨する数値定義は次の通り。

| 除外条件 | 推奨初期値 |
|---|---|
| 支持線明確割れ | `当日安値 < 支持線 - 0.35 * ATR14` かつ `判定価格 < 支持線`。Eへ降格 |
| 直近安値2/3回の安値切り下げ | 直近3比較のうち2回以上で安値切り下げ。D2弱へ降格 |
| 出来高急増の大陰線 | 出来高比150%超、陰線、実体が当日レンジの65%以上。Eへ降格 |
| 出来高100〜150%の陰線 | 出来高比100%以上150%以下、かつ陰線。D2弱へ降格 |
| 直下支持線なし | 判定価格より下、かつ1.0ATR以内に支持線候補がない |
| 終端位置が40%未満 | 終端位置 < 40% |

- 支持線を明確に割れている
- 終端位置が40%未満
- 直近3比較のうち2回以上で安値を切り下げている（D2弱）
- 出来高比150%超の大陰線（E）
- 出来高比100%以上150%以下の陰線（D2弱）
- 現在値の直下に有効な支持線がない

### 9.4 D2強弱の補助判定

反転補助状態は `支持線反発候補` のままとし、単一銘柄詳細の補助表示で `D2` / `D2弱` を分ける。

通常のD2候補に対して、次のいずれかに該当する場合は `D2弱` とする。

- 採用支持線が前日安値単独で、20日安値・75日線・60日安値のいずれとも `0.35ATR` 以内に近接しない
- 直近3比較のうち2回以上で安値を切り下げている
- 出来高比100%以上150%以下、かつ陰線
- D2補助スコアが2点未満

D2補助スコアは次の加点・減点で計算する。

| 条件 | 点数 |
|---|---:|
| 出来高比80%以上 | +1 |
| 下ヒゲ比率20%超 | +1 |
| RSI14が30以上45以下 | +1 |
| 当日安値が採用支持線を下回る | -1 |

### 9.5 表示文と売買行動

- 表示名: `底打ち候補`
- 状態: `支持線反発待ち`
- 行動: `まだ入らない`
- 次確認: `VWAP回復待ち`

## 10. 反転確認 / 旧D3詳細判定

### 10.1 位置づけ

VWAPを回復し、価格モメンタムと終端位置から反転初動を確認できる状態。
反転確認は位置ランクとは独立した補助状態とする。終端位置、出来高、高値更新による強弱は詳細表示にだけ使い、25日線未満での新規エントリー許可には使わない。1Y位置評価と位置ランクは25日線乖離率から判定する。

### 10.2 必須条件

- 現在値が25日線未満
- 現在値がVWAPより上
- 安値切り上げが2回以上
- 終端位置が60%以上
- VWAP上を15分以上連続維持している

高値更新1回以上は反転確認の必須条件にしない。成立した場合は単一銘柄詳細画面で `D3強` とする。
終端位置70%以上も反転確認の必須条件にはせず、成立した場合は単一銘柄詳細画面で `D3強` とする。
出来高比は反転確認の必須条件にしない。単一銘柄詳細画面のD3強弱表示にのみ使う。

### 10.3 推奨追加条件

- 現在値が前日高値または直近抵抗線を試している
- `25日線奪回距離ATR <= 2.0`

推奨追加条件はD3の必須条件にはせず、信頼度または表示ラベルに使う。

### 10.4 表示文

成立した条件とリスクに応じて次を組み合わせる。

- `底打ち初動`
- `VWAP回復`
- `安値切り上げ`
- `反転確認`
- `25日線奪回待ち`
- `戻り売り注意`

### 10.5 単一銘柄詳細画面のD3強弱

D3成立後、高値更新、終端位置、出来高比によって詳細画面の表示を3段階に分ける。
この強弱は位置ランク、反転補助状態および1Y位置評価を変更しない。

| 詳細表示 | 条件 | 表示文 |
|---|---|---|
| D3強 | 高値更新1回以上 | `D3強｜VWAP維持・高値更新` |
| D3強 | 終端位置70%以上 | `D3強｜VWAP維持・終端強い` |
| D3強 | 出来高比80%以上 | `D3強｜VWAP維持・出来高伴う` |
| D3 | 出来高比60%以上80%未満 | `D3｜VWAP維持・出来高やや不足` |
| D3弱 | 出来高比60%未満 | `D3弱｜反転形あるも出来高不足` |

出来高比が欠損する場合は `D3｜VWAP維持・出来高N/A` とする。

### 10.6 D系詳細分類

旧D系の D1a / D1b / D2弱 / D3強 / D3弱 などの詳細分類は、戦略判定や補助判断の材料として残す。単一銘柄Technical出力の冒頭短評は位置ランク、位置表示、崩れまたは反転の補助状態を使って表示する。

### 10.7 単一銘柄Technical出力の冒頭短評

Technical Summary 一覧側では冒頭短評を表示しない。サマリ側は位置ランクと表示名を見出し・分類表示に使い、`テクニカル状態` 列へ崩れまたは反転の補助状態を表示する。

単一銘柄Technical出力では、先頭サマリの直後に次の形式で短評を表示する。
崩れ状態または反転状態は、単一銘柄Technical出力の短評へ位置ランクと分離して表示する。

```text
短評：{位置ランク} {状態表示名}｜{補助状態}｜{1Y位置評価}｜{5日線傾き短評}
短評：{位置ランク} {状態表示名}｜崩れ警戒｜監視のみ｜{崩れ区分}：{理由}｜{5日線傾き短評}
```

1行目は通常状態、2行目は重大な崩れ理由がある場合の形式とする。

短評は位置ランクを基準に表示する。D1a / D1b / D2弱 / D3強 / D3弱などの旧詳細コードは戦略判定側で使い、冒頭短評には表示しない。8%以上10%未満で他指標過熱兆候がある場合は、状態表示名へ `（他指標過熱）` を付ける。

25日線以上では `要確認`、`軽度警戒`、`崩れ警戒` を必要な場合だけ表示する。25日線未満では `VWAP回復・確認不足`、`支持線反発候補`、`反転確認`、`反転未確認` のいずれかを表示する。重大な崩れ条件成立時も位置ランクは維持し、行動だけを `監視のみ` へ上書きして理由を表示する。
短評末尾には5日線軸の該当状況に応じて5日線短評を追加する。

| 5日線軸の該当 | 5日線短評 |
|---|---|
| 該当なし | `5日線良好` |
| `ma5_slope <= 0` | `5日線下向き` |
| `ma5_slope < ma5_slope_prev` | `5日線鈍化` |
| `ma5_slope < ma5_slope_3d_ago` | `5日線失速` |
| 3条件すべて該当 | `5日線悪化` |

該当数が1〜2の場合は、該当した文言を `・` で連結して表示する。
3条件すべて該当する場合は、個別文言を表示せず `5日線悪化` のみ表示する。

冒頭短評の表示例:
```
短評：A1 位置良好｜位置良好｜エントリー優先帯｜5日線良好
短評：A1弱 上方乖離｜中央値マイナス｜押し目確認｜5日線下向き
短評：A1 位置良好｜崩れ警戒｜監視のみ｜即時崩れ：VWAP明確割れ＋終端位置低下｜5日線下向き・5日線鈍化
短評：C1 奪回待ち｜反転確認｜25日線奪回確認まで見送り｜5日線良好
短評：E 25日線下｜支持線反発候補｜反転確認まで見送り｜5日線悪化
```

### 10.8 D系詳細戦略判定

「前場VWAP回復」「後場VWAP回復」の各シナリオが成立した場合の行動指針を並べる。深押し指値戦略は使用しない。前場・後場の区分は取得した5分足の時刻を使用する。

| 　| 前場VWAP回復 | 後場VWAP回復 |
|---|---|---|
| D1a | **△** VWAP回復とD3化は反転観測。新規は25日線奪回待ち | **△** 後場VWAP上維持でも25日線奪回待ち |
| D1b 戻り途中・25日線遠い | **△** VWAP上でも反転確認中 | **△** 持ち越し判断は25日線奪回後 |
| D1 判定保留 | **△** D3条件成立も反転観測に留める | **△** 判定材料不足のため新規見送り |
| D2 支持線反発候補 | **△** VWAP回復と反転状態を確認するが25日線奪回待ち | **△** 後場VWAP上維持でも持ち越し判断は25日線奪回後 |
| D3強 | **○** VWAP維持と出来高を観測。新規は25日線奪回待ち | **○** 持ち越し判断は25日線奪回後 |
| D3 | **○** VWAP回復を観測。新規は25日線奪回待ち | **○** 後場VWAP維持は観測継続条件 |
| D3弱 | **△** 反転形はあるが弱い | **△** 後場VWAP維持でも反転観測に留める |

支持線反発候補からVWAPを回復しても、反転確認条件が揃うまでは `VWAP回復・確認不足` とする。反転確認条件がすべて成立した時点で補助状態を `反転確認` へ変更するが、位置ランクと1Y位置評価は変更しない。

## 12. 単一銘柄Technical出力の崩れ警戒スコア

単一銘柄Technical出力および Technical Summary 一覧では、25日線の上下にかかわらず崩れ警戒を表示する。
崩れスコアは、5日線・25日線を含めない価格構造スコアとする。値が欠損して条件を評価できない場合は加点しない。

実装では各条件を識別子・成立可否・加点を持つ `SignalAtom` として保持する。5日線・25日線の状態も `SignalAtom` として保持するが、崩れスコアには加点せず、重大崩れ理由の三軸判定にのみ使う。

| 条件 | 点数 |
|---|---:|
| 現在値がVWAP未満 | +1 |
| 直近3営業日の安値切り上げがすべて不成立 | +1 |
| 直近3営業日の高値更新がすべて不成立 | +1 |
| 終端位置が40%未満 | 0点。T1/T3の複合トリガー監査用シグナルとしてのみ保持 |
| 出来高20日平均比が100%超、かつ陰線または上値失速 | +1 |
| 直下支持線までの距離が0.7ATR超 | +1 |

5日線軸は次の条件から短評と重大崩れ理由を作る。崩れスコアには加点しない。

| 条件 | 内部理由 |
|---|---|
| `ma5_slope <= 0` | 5日線下向き |
| `ma5_slope < ma5_slope_prev` | 5日線鈍化 |
| `ma5_slope < ma5_slope_3d_ago` | 5日線失速 |

短評では、該当なしなら `5日線良好`、該当数が1〜2なら該当文言を連結、3条件すべて該当なら個別文言を削除して `5日線悪化` のみ表示する。

25日線軸は `当日25日線 < 5営業日前25日線` を `25日線下向き` とする。横ばいは25日線悪化として扱わず、崩れスコアにも加点しない。

25日線の崩れ判定では、傾きの絶対値や、傾きが5営業日前より悪化しているかは使わない。
現行実装は、当日25日線と5営業日前25日線の水準だけを比較する。

| 判定 | 条件 | 意味 |
|---|---|---|
| 25日線上向き | `当日25日線 > 5営業日前25日線` | 中期線は上向き |
| 25日線下向き | `当日25日線 < 5営業日前25日線` | 中期線は下向き。重大崩れ理由の補助軸に使う |
| 25日線横ばい | `当日25日線 == 5営業日前25日線` | 悪化扱いしない |
| 判定不可 | 当日25日線または5営業日前25日線が欠損 | 25日線軸では加点・陥落理由に使わない |

25日線下向きだけでは重大崩れにしない。`5日線下向き` と同時成立した場合は `下行初動`、崩れスコア2点以上かつ価格構造悪化と同時成立した場合は `構造崩れ` として扱う。

崩れ状態判定では、崩れ警戒スコアから重大崩れ条件を派生させる。

25日線乖離率が0%以上の全位置ランクでは、次のいずれかを満たす場合に補助状態を `崩れ警戒` とし、1Y位置評価を `監視のみ` へ上書きする。位置ランクは変更しない。

| 区分 | 条件 |
|---|---|
| 即時崩れ | 下表 T1〜T4 のいずれかが成立 |
| 下行初動 | 5日線下向き、かつ25日線下向き |
| 下行初動 | 5日線下向き、かつVWAP割れ |
| 構造崩れ | 25日線下向き、かつ崩れスコア2点以上、かつ価格構造悪化 |
| 高リスク | 崩れスコア4点以上 |

| トリガー | 条件 |
|---|---|
| T1 VWAP明確割れ＋終端位置低下 | `現在値 < VWAP - 0.2 * ATR14` かつ終端位置低下 |
| T2 VWAP明確割れ＋安値切り上げ失敗 | `現在値 < VWAP - 0.2 * ATR14` かつ安値切り上げ失敗 |
| T3 出来高陰線/上値失速＋終端位置低下 | 出来高陰線/上値失速、かつ終端位置低下 |
| T4 支持線崩落 | 直下支持線が遠い、かつVWAP割れ |

5日線のみ、25日線のみでは重大崩れにしない。重大条件に達しない場合、崩れスコア1点は `要確認`、2〜3点は `軽度警戒` と表示し、位置ランクを維持する。

### 12.1 重大崩れ理由の表示

単一銘柄Technical出力で重大崩れ条件が成立した場合、短評に次の形式で理由を表示する。Technical Summary 一覧では位置ランクを維持し、`テクニカル状態` 列へ `崩れ警戒`、1Y位置評価へ `監視のみ` を表示する。

```text
{崩れ区分}：{陥落理由}
```

複数条件が同時に成立した場合も表示する理由は1件とし、次の優先順位で決める。

| 優先順位 | 陥落理由 | 判定条件 |
|---:|---|---|
| 1 | 即時崩れ：VWAP明確割れ＋終端位置低下 | T1 |
| 2 | 即時崩れ：VWAP明確割れ＋安値切り上げ失敗 | T2 |
| 3 | 即時崩れ：出来高陰線/上値失速＋終端位置低下 | T3 |
| 4 | 即時崩れ：支持線崩落 | T4 |
| 5 | 下行初動：5日線下向き＋25日線下向き | 5日線下向き、かつ25日線下向き |
| 6 | 下行初動：5日線下向き＋VWAP割れ | 5日線下向き、かつVWAP割れ |
| 7 | 構造崩れ：25日線下向き＋崩れスコア中以上＋価格構造悪化 | 25日線下向き、かつ崩れスコア2点以上、かつ価格構造悪化 |
| 8 | 高リスク：崩れスコア高リスク | 上記が不成立、かつ崩れスコア4点以上 |

**定義補足：**

- **陰線：** `終値 < 始値` かつ実体が `0.15ATR` 以上
- **上値失速：** 上ヒゲが当日値幅の45%以上、かつ実体の1.5倍以上
- **直下支持線：** 現在値より下にある25日線、前日安値、20日安値、75日線、60日安値のうち最も近い価格
  - 候補がない場合、またはATRを取得できない場合は距離条件を加点しない
- **25日線下向き：** `当日25日線 < 5営業日前25日線`
- **5日線傾き比較：**
  - `ma5_slope = 当日5日線 - 前日5日線`
  - `ma5_slope_prev = 前日5日線 - 2営業日前5日線`
  - `ma5_slope_3d_ago = 3営業日前5日線 - 4営業日前5日線`

### 12.2 崩れスコアのランク別ラベル表示

表示は `崩れ {score}/5：{ラベル}` 形式とする。

| ランク | 0〜1点 | 2〜3点 | 4〜5点 |
|---|---|---|---|
| A*, B*, E | 崩れ軽微 | 上値重い | 崩れ警戒 |
| C1 | 押し目候補 | VWAP回復待ち | 押し目ではなく崩れ警戒 |
| D1 | 戻り良好 | 25日線奪回待ち | 戻り売り警戒 |

表示例: `崩れ 4/5：原則回避｜新規買い回避`

### 12.2.1 単一銘柄出力の実戦短評

単一銘柄Technical出力では、ランク別ラベルの代わりに実戦用の短評を表示する。
スコア計算と重大崩れ条件は変更せず、短評だけを次の点数帯で表示する。

| 崩れスコア | 短評 | 補足 |
|---:|---|---|
| 0〜1 | 候補 | 買い条件は別確認 |
| 2〜3 | 条件付き候補 | 後場VWAP上維持・価格構造回復を確認 |
| 4 | 原則回避 | 新規買い回避 |
| 5 | ほぼ触らない | 構造回復まで見送り |

価格構造回復は、VWAP回復・維持、安値切り上げ、高値更新、支持線維持などを指す。終端位置はこの共通短評の条件には使わない。

表示例: `崩れ 2/5：条件付き候補｜後場VWAP上維持・価格構造回復を確認`

### 12.3 実装確認事項

- 現行モデルは `ma5`、`ma5_prev1`、`ma5_slope`、`ma5_slope_prev`、`ma5_slope_3d_ago` を保持する。
- 5日線短評は、該当なしなら `5日線良好`、該当数1〜2なら個別文言、3条件すべて該当なら `5日線悪化` と表示する。
- 崩れスコアの最大値は5点。終端位置、5日線、25日線は崩れスコアに加点せず、終端位置はT1/T3、5日線・25日線は三軸の重大崩れ理由にのみ使う。表示分母、ラベル境界、テスト期待値を5点基準で統一する。

### 12.4 Technical Summary 一覧での表示と並び順

Technical Summary 一覧では、従来の `前日VWAP維持` 列を表示せず、代わりに `崩れスコア` 列を表示する。

列の表示形式は崩れ警戒スコアの数値のみとし、短評やラベルは表示しない。

各位置ランク内では銘柄を崩れスコアの低い順に並べる。同点の場合は WatchList の順序を維持する。

## 13. 底打ち初動・ホールド判定

### 13.1 底打ち初動判定

底打ち初動判定は現在値が25日線未満の場合だけ表示し、
反転補助状態が `反転確認` の場合を `成立`、それ以外を `未成立` とする。

### 13.2 ホールド判定

ホールド判定は次の条件を使う。直下支持線の距離はATR14で正規化する。
条件が重複する場合は上から順に評価し、最初に一致した判定を採用する。
どの条件にも完全一致しない場合は `△` とする。

| 判定 | 条件 |
|---|---|
| × | VWAP未満、25日線未満、直近3営業日の安値切り上げがすべて不成立、直下支持線まで0.7ATR超をすべて満たす |
| △ | VWAP以上だが25日線未満、または終端位置50%未満、または出来高20日平均比80%未満 |
| ◎ | 25日線以上、VWAP以上、終端位置50%以上、出来高20日平均比80%以上、直下支持線まで0.7ATR以内をすべて満たす |
| ○ | VWAP以上、かつ「25日線以上または25日線まで0.7ATR以内」、かつ直近3営業日の安値切り上げが1つ以上 |
| △ | 上記のいずれにも一致しない |

直下支持線は現在値より下にある25日線、前日安値、20日安値、75日線、60日安値のうち最も近い価格を使う。支持線候補がない、またはATR14が欠損・0で距離を算出できない場合は、支持線が遠いとは判定しないため、この理由だけで `×` にはしない。

株価・VWAP・25日線・25日線乖離率のいずれかが欠損し、ホールド判定の前提を満たせない場合、単一銘柄Technical出力ではホールド判定を `N/A` とする。その他の補助値が欠損して上表の条件に一致しない場合は、既定値の `△` とする。現行実装では上側抵抗線までの余地や25日線傾きはホールド判定に使わない。

- `銅先物(COMEX)`
- `WTI原油`

各行は yFinance の日足から以下を計算する。

| 指標 | 計算 |
|---|---|
| 直近値 | 当日終値 |
| 前日騰落 | 当日終値 - 前日終値 |
| 5日移動平均乖離 | 25日線乖離率と同じ方式で計算 |
| 25日移動平均乖離 | (現在値 - 25日線) / 25日線 * 100 |
| RSI14 | 14本ベースで計算 |

US Market の取得失敗は Technical Summary 全体の失敗にしない。
取得できない指標は skipped として理由を保持し、表示可能な指標だけを出力する。

## 15. セクター地合評価

### 15.1 目的

監視銘柄ファイル内のセクタータグを使い、同一テーマ・同一セクター内の横断的な地合いを評価する。
セクター地合は単一銘柄の買い判定を直接決めず、VWAP回復、終端位置、25日線位置、崩れスコア、出来高比を補助判断として集約する。

### 15.2 セクタータグ

監視銘柄ファイルの銘柄コードと同じ行に、以下のタグ名または短縮タグが含まれる場合、その銘柄を該当セクターに所属させる。
行頭の `-` や `*` は Markdown の箇条書き記号として扱い、タグ名には含めない。
タグがない銘柄はセクター地合評価から除外し、分母にも含めない。
1銘柄に複数タグがある場合は、複数セクターへ重複計上する。

| 正式セクター名 | 短縮タグ例 |
|---|---|
| 半導体材料・装置 | 半導体材料、半導体装置 |
| 電線・電力インフラ | 電線、電力インフラ |
| データセンター・電源、空調 | データセンター、電源、空調 |
| 電子部品・電子機器 | 電子部品、電子機器 |
| FA・機械・ロボット | FA、機械、ロボット |
| 防衛・重工 | 防衛、重工 |
| 商社・資源 | 商社、資源 |
| ディフェンシブ・内需 | ディフェンシブ、内需 |
| 水処理・環境インフラ | 水処理、環境インフラ |

短縮タグは銘柄名内部の文字列ではなく、同じ行に区切られたタグとして現れた場合だけ採用する。
例: `三菱重工 (7011)` はタグなし、`三菱重工 (7011) 防衛` は `防衛・重工` とする。

### 15.3 セクター集計指標

| 指標 | 定義 |
|---|---|
| VWAP上比率 | セクター所属銘柄のうち、現在値がVWAP以上の銘柄割合。日足参考VWAPも判定に含める |
| 終端位置中央値 | セクター所属銘柄の当日終端位置の中央値 |
| 崩れスコア中央値 | セクター所属銘柄の崩れスコア中央値 |
| 25日線上比率 | セクター所属銘柄のうち、現在値が25日線以上の銘柄割合 |
| 出来高比中央値 | セクター所属銘柄の出来高20日平均比の中央値 |

欠損値は各指標の分母から除外する。全銘柄で算出不能な指標は `N/A` とする。

### 15.4 指標別ラベル

VWAP上比率:

| 条件 | 判定 |
|---|---|
| 70%以上 | セクター買い優勢 |
| 50%以上70%未満 | 中立〜やや強い |
| 30%以上50%未満 | まちまち |
| 30%未満 | セクター売り優勢 |

終端位置中央値:

| 条件 | 判定 |
|---|---|
| 70%以上 | 高値圏維持、買い優勢 |
| 50%以上70%未満 | 反発中 |
| 30%以上50%未満 | 戻り鈍い |
| 30%未満 | 売り圧優勢 |

崩れスコア中央値:

| 条件 | 判定 |
|---|---|
| 0以上2以下 | 健全 |
| 3以上4以下 | 注意 |
| 5以上6以下 | 崩れ警戒 |
| 7以上 | 回避 |

出来高比中央値:

| 条件 | 判定 |
|---|---|
| 80%以上 | 実需あり |
| 50%以上80%未満 | 普通 |
| 30%以上50%未満 | 薄い |
| 30%未満 | 信頼度低い |

### 15.5 セクター総合判定

| 判定 | 条件 |
|---|---|
| 崩れ地合い | VWAP上比率30%未満、かつ崩れスコア中央値5以上、かつ出来高増下落銘柄が1銘柄以上 |
| 強い上昇地合い | VWAP上比率70%以上、終端位置中央値70%以上、崩れスコア中央値2以下 |
| 押し目買い優勢 | VWAP上比率60%以上、かつ25日線上比率70%以上、かつ崩れスコア中央値4以下 |
| まちまち | VWAP上比率40%以上60%未満、または終端位置中央値40%以上60%未満 |
| 戻り売り優勢 | VWAP上比率40%未満、かつ終端位置中央値40%未満 |

上から順に判定し、最初に一致したものを採用する。
出来高増下落銘柄は既存 Technical Summary の `volume_spike_bearish` を使う。
上記の主要条件に一致しない場合や判定材料が不足する場合は、強弱を断定せず `まちまち` とする。
コメントには指標別ラベルに加えて、対象が1〜2銘柄の少数サンプルであること、出来高増下落銘柄数を補足表示する。

### 15.6 単一銘柄Technical出力での表示

単一銘柄Technical出力では、`地合評価` ボタンを押した場合のみ、監視銘柄全体から算出した該当セクターの地合を `■セクター地合` として本文末尾に追加する。Technical の `取得` ボタンでは自動追加しない。
表示対象は、選択銘柄にセクタータグがある場合に限る。
タグなし銘柄、または該当セクターの集計結果が作れない場合は表示しない。
この表示は単一銘柄のTechnicalランクや戦略判定を直接変更せず、同テーマ内の横断的な補助情報として扱う。
