# Technical ランキング・指標仕様

## 1. 目的

本書は Technical 分析に必要な指標計算、VWAP定義、ローソク足型判定、ランキング分類条件を一元管理する。
ランキング分類は、単一銘柄 Technical 出力と監視銘柄 Technical Summary で共通とする。

- 画面・表示仕様：`docs/screen_spec.md`
- 現行実装状況：`docs/current_implementation_spec.md`

## 2. Technical 計算 / 日足ベースの指標

日足ベースで次を計算する。

| 指標 | 定義 |
|---|---|
| 5日移動平均 | 直近5営業日の終値の算術平均 |
| 5日線の傾き | `当日5日線 - 前日5日線`。0未満なら短期線低下 |
| 前日5日線の傾き | `前日5日線 - 2営業日前5日線` |
| 3営業日前5日線の傾き | `3営業日前5日線 - 4営業日前5日線` |
| 25日移動平均 | 直近25営業日の終値の算術平均 |
| 5営業日前25日線 | 5営業日前時点の25日移動平均。25日線の向き判定に使う |
| 25日線からの乖離率 | `(現在値 - 25日線) / 25日線 * 100 %` |
| RSI14 | 14本の価格変動に対する上昇幅の割合。`100 * (平均上昇幅 / (平均上昇幅 + 平均下降幅))` |
| ATR14 | 14本の実現値幅の指数平滑移動平均。TR = `max(高値 - 安値, 高値 - 前日終値, 前日終値 - 安値)` |
| 当日値幅とATR比 | `当日値幅 / ATR14` |
| 当日終端位置 | `(現在値 - 当日安値) / (当日高値 - 当日安値) * 100` |
| 前日高値更新 | `当日高値 > 前日高値` |
| 前日安値維持 | `当日安値 >= 前日安値` |
| 前日出来高20日平均比 | `当日出来高 / 20日平均出来高 * 100` |
| 5日/20日/60日の高値/安値 | 直近N営業日の高値の最大値、安値の最小値 |

## 3. VWAP関連指標

### 3.1 日中VWAP（場中の短期移動平均代わり）

日中VWAPは、5分足が取得できる場合は5分足から計算する。

**計算式：**
```
VWAP = Σ(5分足の(高値+安値+終値)/3 × 出来高) / Σ(5分足の出来高)
```

取得できない場合は日足の参考値 `(当日高値 + 当日安値 + 当日終値) / 3` を日中VWAP代替値として使う。

### 3.2 前日全体VWAP・前場VWAP・後場VWAP

前日5分足から以下を計算する。

| 指標 | 定義 |
|---|---|
| 前日全体VWAP | 前日全営業時間の全5分足から計算したVWAP |
| 前日前場VWAP | 前日前場（09:00～11:30）の5分足から計算したVWAP |
| 前日後場VWAP | 前日後場（12:30～15:00）の5分足から計算したVWAP |
| 前場VWAP維持 | 前日前場の最終5分足終値が前日前場VWAP以上 |
| 後場VWAP維持 | 前日終値が前日後場VWAP以上 |
| 前日終値の後場VWAP位置 | `前日終値 > 前日後場VWAP` の場合 `上`、それ以外は `下` |

後場評価は、前日後場の始値・高値・安値・終値・後場VWAPから次のラベルを返す。

| ラベル | 条件 |
|---|---|
| `後場VWAP割` | 前日終値が前日後場VWAP以下 |
| `失速もVWAP維持` | 後場VWAPを維持しているが、後場騰落率が -1% 未満、または後場終端位置が30%未満 |
| `後場上昇` | 後場終値が後場始値より高く、後場終端位置が70%以上。または後場騰落率が1%超 |
| `高値維持` | 後場終端位置が50%以上、かつ後場騰落率が -1%以上1%以下 |
| `横ばいVWAP維持` | 後場終端位置が30%以上50%未満、かつ後場騰落率が -1%以上1%以下。上記以外でVWAPを維持している場合もこれに含める |

### 3.3 VWAP位置判定

| 判定 | 条件 |
|---|---|
| VWAP上 | `現在値 > VWAP` |
| VWAP接近 | `VWAP - 0.2ATR14 <= 現在値 <= VWAP` |
| VWAP以下 | `現在値 <= VWAP` |
| VWAP明確われ|　`現在値 <= VWAP－0.35× ATR14　` |

### 3.4 VWAP維持時間

直近のVWAP上抜け後、連続してVWAP上にいる時間（分単位）。
現行実装では、確定済み5分足だけを対象に、直近セッション内で終値がVWAPを上回った連続本数を数える。前場は09:00以降、後場は12:30以降を別セッションとして扱い、昼休みをまたいだ維持本数は引き継がない。連続本数 `3本以上` を 
`VWAP15分維持` とする。

## 4. ローソク足型と髭（ひげ）

###　4.1　陽線･陰線

| 種別 | 条件 |
|---|---|
| 陽線 | `終値 > 始値` |
| 陰線 | `終値 < 始値` |
| 実体条件付き陰線 | 陰線 かつ 実体が `0.15ATR` 以上 |

### 4.2 ローソク足型判定

前日の日足OHLCから判定する。

| 条件 | ラベル |
|---|---|
| `range <= 0` または欠損 | `N/A` |
| 実体比 < 10% または `始値 == 終値` | `十字` |
| 実体比 < 30% | `小陽線` / `小陰線` |
| 実体比 < 65% | `陽線` / `陰線` |
| それ以外 | `大陽線` / `大陰線` |

**実体比の定義：**
- 陽線の場合：`(終値 - 始値) / (高値 - 安値) * 100`
- 陰線の場合：`(始値 - 終値) / (高値 - 安値) * 100`

**range の定義：**`高値 - 安値`

### 4.2 髭（ひげ）判定

ローソク足の上下の髭を判定する。

| ヒゲ種別 | 条件 |
|---|---|
| 上髭 | 上ヒゲ比率 >= 30% かつ 実体の1.5倍以上 かつ 下ヒゲより長い |
| 下髭 | 下ヒゲ比率 >= 30% かつ 実体の1.5倍以上 かつ 上ヒゲより長い |
| ヒゲなし | 上記いずれでもない |
| N/A | `range <= 0` または欠損 |

**ヒゲ比率の定義：**

```
上ヒゲ比率 = (高値 - max(始値, 終値)) / (高値 - 安値) * 100
下ヒゲ比率 = (min(始値, 終値) - 安値) / (高値 - 安値) * 100
```

**実体の定義：**
```
実体 = abs(終値 - 始値)
```

## 5. 共通指標定義

### 5.1 基本指標

| 指標 | 定義 |
|---|---|
| 25日線位置 | `現在値 < 25日線` をD系判定の前提とする |
| 終端位置 | `(現在値 - 当日安値) / (当日高値 - 当日安値) * 100` |
| 25日線距離ATR | `(現在値 - 25日線) / ATR14`　|
| 25日線奪回距離ATR | `abs(現在値 - 25日線) / ATR14`。D1a / D1b の25日線接近判定用　|
| 支持線距離ATR | `abs(当日安値 - 支持線) / ATR14` |
| 出来高比 | `当日出来高 / 20日平均出来高 * 100` |

### 5.2 判定価格と評価コンテキスト

- **日足と同じ日付の5分足があり、最新5分足が15:25より前：** 最新5分足の終値を現在値として使う
- **日足と同じ日付の5分足があり、最新5分足が15:25以降：** 確定した日足終値を使う
- **日足より新しい日付の5分足があり、最新5分足が15:25より前：** 最新5分足の終値を現在値として使う
- **日足より新しい日付の5分足があり、最新5分足が15:25以降：** 最新5分足の終値を暫定終値として使う
- **5分足がない、または同一/新規日付として使えない場合：** 日足終値を使う

判定価格、判定時刻、価格ソースを同じ評価コンテキストに保持する。現行実装では、昼休みや休日を別条件として分岐せず、利用可能な5分足の日付と最新時刻で評価価格を決める。

### 5.3 ATR14 欠損時の方針

- ATR14 が0または欠損の場合、ATRを使う必須条件は `判定保留` とする
- ATRを参照する指標（例：距離計算、RR計算）も合わせて `N/A` または `算出不可` とする

## 6. 上値失速の定義

```
上ヒゲが当日値幅の45%以上、かつ実体の1.5倍以上
```
定義式：
```
上ヒゲ比率 >= 45% かつ 上ヒゲ >= 実体 * 1.5
```

## 7. Technical Summary ランキング分類

### 7.1 基本方針

- 25日線以上の A / B / C 系ランクは、25日線乖離率のレンジを主軸に分類する
- 25日線未満の D / E 系ランクは、VWAP回復、支持線反発、反転確認を主軸に分類する
- 25日線乖離率は D1 / D2 / D3 の必須条件にしない
- D2 は「まだ入らない候補」、D3 は「小さく入れる候補」とする
- 25日線未満かつVWAP上でD3を満たさない銘柄は、25日線奪回距離ATRにより D1a / D1b へ分類する
- 必須データが欠損した場合は、成立扱いにせず `判定保留` とする
- 全ランキングで、場中は現在値、大引け後は当日終値を判定価格に使う
- `Focus_theme`、銘柄名キーワード、テーマ性はランキング分類条件に使わない

### 7.2 A / B / C 系の補助条件

#### 7.2.1 過熱条件

B1の `25日線乖離率 8%以上10%未満` では、次のいずれかを満たす場合を過熱条件ありとする。

| 条件 | 判定 |
|---|---|
| 3日騰落率 | `3日騰落率 > 6%` |
| 60日レンジ位置 | `60日レンジ位置 >= 80%` |
| RSI14 | `RSI14 >= 70` |
| 当日終端位置 | `当日終端位置 >= 85%` |

過熱条件がない場合、`25日線乖離率 8%以上10%未満` は A2 とする。

#### 7.2.2 崩れ条件（簡略版）

25日線乖離率によるベースランクを先に決定し、その後に `12. 単一銘柄Technical出力の崩れ警戒スコア` を使って崩れ状態ラベルと C2 陥落を判定する。本節ではランキング側の点数表を持たず、崩れスコアの正本は12章に一元化する。

本節は 25日線乖離率 0%以上 の銘柄に適用する。A2 / A1 / A1弱 / C1 は、12章の C2 陥落条件が成立した場合のみ `C2 崩れ警戒` へ分類する。C2 陥落条件に達しない場合はベースランクを維持し、短評・補助ラベルに崩れ状態だけを併記する。

崩れ状態ラベルは次の通りとする。

| 条件 | ラベル | ランク影響 |
|---|---|---|
| C2陥落条件成立 | 崩れ警戒 | C2へ分類 |
| 崩れスコア2〜3点、かつC2陥落条件不成立 | 軽度警戒 | ベースランク維持 |
| 崩れスコア1点 | 要確認 | ベースランク維持 |
| 崩れスコア0点 | 崩れ条件なし | ベースランク維持 |

上から順に評価し、最初に一致した行を採用する。


### 7.3.1 全ランク一覧

| ランク | 表示名 | 条件 | 行動 |
|---|---|---|---|
| B2 | 過熱極大 | `25日線乖離率 >= 12%`、または `25日線乖離率 >= 10%` かつ `25日線距離ATR > 3.0` | 
| B1 | 過熱後半 | `25日線乖離率 >= 10%` かつ `< 12%`、または `25日線乖離率 >= 8%` かつ `< 10%` かつ過熱条件あり | 
| A2 | やや過熱 | `25日線乖離率 >= 8%` かつ `< 10%` かつ過熱条件なし、かつC2陥落条件なし | 
| A1 | 位置良好 | `25日線乖離率 >= 6%` かつ `< 8%`、かつC2陥落条件なし |
| A1弱 | 押し目候補 | `25日線乖離率 >= 4%` かつ `< 6%`、かつC2陥落条件なし |
| C2 | 崩れ警戒 | `25日線乖離率 >= 0%`、かつC2陥落条件あり |
| C1 | 25日線接近 | `25日線乖離率 >= 0%` かつ `< 4%`、かつC2陥落条件なし |
| D1 | 戻り途中 | 25日線下、VWAP上、D3不成立 |
| D2 | 底打ち候補 | 25日線下、VWAP以下、支持線反発候補 |
| D3 | 底打ち初動 | 25日線下、VWAP回復、反転確認 |
| E | 下落トレンド | 25日線下でD1/D2/D3不成立 | 

表示順は `B2 -> B1 -> A2 -> A1 -> A1弱 -> C2 -> C1 -> D1 -> D2 -> D3 -> E` とする。

### 7.4 25日線乖離率による位置説明・行動補助

25日線乖離率は、A / B / C 系ではランク分類の主軸とし、D系では位置説明と行動補助に使う。
実際のランクは過熱条件、C2陥落条件、D系の反転条件も含めて判定する。
A2 / A1 / A1弱 / C1 では、C2陥落条件に達しない崩れ状態をランク変更ではなく短評・補助ラベルに使う。

### 7.5 D系ランクの判定順

現在値が25日線未満の場合、次の順で判定する。

1. VWAP上なら D3 を判定する
2. D3不成立なら、25日線奪回距離ATRにより D1a / D1b を判定する
3. VWAP以下なら D2 を判定する
4. D1 / D2 / D3 のいずれにも該当しない場合は E とする

## 8. D1 戻り途中 / 25日線奪回待ち

### 8.1 位置づけ

VWAPは回復したが、反転確認は不十分で、25日線が上値抵抗になっている状態。
新規買いを急がず、25日線奪回または上値の確認を待つ。

### 8.2 必須条件

- 現在値が25日線未満
- 現在値がVWAPより上
- D3条件を満たさない

### 8.3 詳細画面のD1サブ分類

D1a / D1b はランキングコードを増やさず、単一銘柄詳細画面だけのサブ分類とする。

| サブ分類 | 条件 | 表示名 | 意味 |
|---|---|---|---|
| D1a | `25日線奪回距離ATR <= 2.0` | `戻り途中・25日線接近` | 25日線奪回を試せる距離だが、利確圧力に注意 |
| D1b | `25日線奪回距離ATR > 2.0` | `戻り途中・25日線遠い` | 25日線奪回まで値幅があり、戻り確認を継続 |

ATR14または25日線が欠損する場合もランキングはD1とし、詳細サブ分類だけを `D1 判定保留` とする。

### 8.4 表示文

状態に応じて次を組み合わせる。

- `戻り途中`
- `25日線奪回待ち`
- `上値確認中`
- `25日線接近なら利確圧注意`
- `25日線まで距離あり`

### 8.5 売買行動

- 基本は監視継続
- 25日線接近時は利確圧力を警戒する
- 追加買いは25日線奪回後を基本とする
- D1bはD1aよりも25日線奪回までの不確実性が高いため、監視継続を優先する

## 9. D2 底打ち候補 / 支持線反発待ち

### 9.1 位置づけ

支持線付近で反発の兆候はあるが、VWAPを回復していない状態。
D2は「まだ入らない候補」とし、新規買いは待つ。

### 9.2 必須条件

- 現在値が25日線未満
- 現在値がVWAP以下
- いずれかの支持線について `abs(当日安値 - 支持線) <= 0.35 * ATR14`
- 終値または現在値が、採用した支持線から `+0.1 * ATR14` 以上戻っている
- `VWAP - 1.0 * ATR14 <= 現在値 <= VWAP`
- 除外条件に該当しない

支持線候補は、前日安値、20日安値、75日線、60日安値とする。
25日線は上値抵抗として扱い、D2の支持線候補には含めない。

前日安値単独を支持線として採用する場合は `D2弱` とする。`D2弱` はサマリ分類では `D2` と同じ扱いにし、単一銘柄詳細の補助表示だけで区別する。
ただし、前日安値が20日安値、60日安値、75日線のいずれかと `0.35 * ATR14` 以内に近接している場合は、通常の支持線として扱う。

### 9.3 除外条件

推奨する数値定義は次の通り。

| 除外条件 | 推奨初期値 |
|---|---|
| 支持線明確割れ | `当日安値 < 支持線 - 0.35 * ATR14` かつ `判定価格 < 支持線`。Eへ降格 |
| 直近安値2/3回の安値切り下げ | 直近3比較のうち2回以上で安値切り下げ。D2弱へ降格 |
| 出来高急増の大陰線 | 出来高比150%超、陰線、実体が当日レンジの65%以上。Eへ降格 |
| 出来高100〜150%の陰線 | 出来高比100%以上150%以下、かつ陰線。D2弱へ降格 |
| 直下支持線なし | 判定価格より下、かつ1.0ATR以内に支持線候補がない |
| 終端位置が40%未満 | 終端位置 < 40% |

- 支持線を明確に割れている
- 終端位置が40%未満
- 直近3比較のうち2回以上で安値を切り下げている（D2弱）
- 出来高比150%超の大陰線（E）
- 出来高比100%以上150%以下の陰線（D2弱）
- 現在値の直下に有効な支持線がない

### 9.4 D2強弱の補助判定

D2のランキング分類は `D2` のままとし、単一銘柄詳細の補助表示で `D2` / `D2弱` を分ける。

通常のD2候補に対して、次のいずれかに該当する場合は `D2弱` とする。

- 採用支持線が前日安値単独で、20日安値・75日線・60日安値のいずれとも `0.35ATR` 以内に近接しない
- 直近3比較のうち2回以上で安値を切り下げている
- 出来高比100%以上150%以下、かつ陰線
- D2補助スコアが2点未満

D2補助スコアは次の加点・減点で計算する。

| 条件 | 点数 |
|---|---:|
| 出来高比80%以上 | +1 |
| 下ヒゲ比率20%超 | +1 |
| RSI14が30以上45以下 | +1 |
| 当日安値が採用支持線を下回る | -1 |

### 9.5 表示文と売買行動

- 表示名: `底打ち候補`
- 状態: `支持線反発待ち`
- 行動: `まだ入らない`
- 次確認: `VWAP回復待ち`

## 10. D3 底打ち初動 / 反転確認

### 10.1 位置づけ

VWAPを回復し、価格モメンタムと終端位置から反転初動を確認できる状態。
D3は「小さく入れる候補」とし、通常サイズのエントリーとは区別する。

### 10.2 必須条件

- 現在値が25日線未満
- 現在値がVWAPより上
- 安値切り上げが2回以上
- 終端位置が60%以上
- VWAP上を15分以上連続維持している

高値更新1回以上はD3分類の必須条件にしない。成立した場合は単一銘柄詳細画面で `D3強` とする。
終端位置70%以上もD3分類の必須条件にはせず、成立した場合は単一銘柄詳細画面で `D3強` とする。
出来高比はD3分類の必須条件にしない。単一銘柄詳細画面のD3強弱表示にのみ使う。

### 10.3 推奨追加条件

- 現在値が前日高値または直近抵抗線を試している
- `25日線奪回距離ATR <= 2.0`

推奨追加条件はD3の必須条件にはせず、信頼度または表示ラベルに使う。

### 10.4 表示文

成立した条件とリスクに応じて次を組み合わせる。

- `底打ち初動`
- `VWAP回復`
- `安値切り上げ`
- `反転確認`
- `25日線奪回待ち`
- `戻り売り注意`

### 10.5 単一銘柄詳細画面のD3強弱

D3成立後、高値更新、終端位置、出来高比によって詳細画面の表示を3段階に分ける。
この強弱はD3ランキング分類を変更しない。

| 詳細表示 | 条件 | 表示文 |
|---|---|---|
| D3強 | 高値更新1回以上 | `D3強｜VWAP維持・高値更新` |
| D3強 | 終端位置70%以上 | `D3強｜VWAP維持・終端強い` |
| D3強 | 出来高比80%以上 | `D3強｜VWAP維持・出来高伴う` |
| D3 | 出来高比60%以上80%未満 | `D3｜VWAP維持・出来高やや不足` |
| D3弱 | 出来高比60%未満 | `D3弱｜反転形あるも出来高不足` |

出来高比が欠損する場合は `D3｜VWAP維持・出来高N/A` とする。

### 10.6 D系詳細分類

D系の D1a / D1b / D3強 / D3弱 などの詳細分類は、戦略判定や補助判断の材料として残す。単一銘柄Technical出力の冒頭短評は詳細分類文言ではなく、ランク、表示名、位置の説明を使って統一表示する。

### 10.7 単一銘柄Technical出力の冒頭短評

Technical Summary 一覧側では冒頭短評を表示しない。サマリ側はランクコードと表示名のみを見出し・分類表示に使う。

単一銘柄Technical出力では、先頭サマリの直後に次の形式で短評を表示する。
崩れ状態ラベルは内部のランク補助判定として保持するが、単一銘柄Technical出力の短評には表示しない。

```text
短評：{ランク} {表示名} {位置の説明}｜{5日線傾き短評}
短評：C2 崩れ警戒 {位置の説明}｜{崩れ区分}：{陥落理由}｜{5日線傾き短評}
```

1行目は通常ランク、2行目は C2 陥落理由がある場合の形式とする。

短評はランキングコードを基準に表示する。D1a / D1b / D2弱 / D3強 / D3弱 などの詳細分類は戦略判定側で使い、冒頭短評には表示しない。
A2は現行ランクとして残し、やや過熱の押し目待ちとして表示する。

| ランク | 表示名 | 位置の説明 |
|---|---|---|
| B2 | 過熱極大 | 上値余地より、逆行リスクが高い位置 |
| B1 | 過熱後半 | 上昇トレンドはのこるが、逆行率高い。 |
| A2 | やや過熱 | やや過熱。追随より押し目待ち。 |
| A1 | 位置良好 | リターン良好、買い候補 |
| A1弱 | 押し目候補 | 良好だが、短期逆行も多い。 |
| C1 | 25日線接近 | 方向未確定 |
| C2 | 崩れ警戒 | 監視のみ |
| D1 | 戻り途中 | 25日線奪回待ち。上値確認中。 |
| D2 | 底打ち候補 | 支持線反発待ち。 |
| D3 | 底打ち初動 | VWAP回復。安値切り上げ・反転確認。 |
| E | 下落トレンド | 買い見送り。反転確認待ち。 |


A2 / A1 / A1弱 / C1 では、崩れ状態ラベルが `要確認` または `軽度警戒` でもランクは維持するが、単一銘柄Technical出力の短評には表示しない。
C2陥落条件に達した場合のみ `C2 崩れ警戒` とし、単一銘柄Technical出力の短評には短縮した陥落理由を表示する。
D / E 系ではランキング用崩れ状態ラベルを短評に表示しない。崩れ警戒の詳細は、冒頭短評の直後に表示する単一銘柄Technical出力用の崩れスコアで確認する。
短評末尾には5日線軸の該当状況に応じて5日線短評を追加する。

| 5日線軸の該当 | 5日線短評 |
|---|---|
| 該当なし | `5日線良好` |
| `ma5_slope <= 0` | `5日線下向き` |
| `ma5_slope < ma5_slope_prev` | `5日線鈍化` |
| `ma5_slope < ma5_slope_3d_ago` | `5日線失速` |
| 3条件すべて該当 | `5日線悪化` |

該当数が1〜2の場合は、該当した文言を `・` で連結して表示する。
3条件すべて該当する場合は、個別文言を表示せず `5日線悪化` のみ表示する。

 

冒頭短評の表示例:
```
短評：A1 位置良好 リターン良好、買い候補｜5日線良好
短評：A1 位置良好 リターン良好、買い候補｜5日線鈍化
短評：A1弱 押し目候補 良好だが、短期逆行も多い。｜5日線下向き
短評：C2 崩れ警戒 監視のみ｜即時崩れ：VWAP明確割れ＋終端位置低下｜5日線下向き・5日線鈍化
短評：C2 崩れ警戒 監視のみ｜高リスク：崩れスコア高リスク｜5日線悪化
短評：E 買い不可 監視のみ。新規買い不可。｜5日線悪化
```

### 10.8 D系詳細戦略判定

「深押し指値」「前場VWAP回復」「後場VWAP回復」の各シナリオが成立した場合の
行動指針を並べる。前場・後場の区分は取得した5分足の時刻を使用する。

| 　| 深押し指値 | 前場VWAP回復 | 後場VWAP回復 |
|---|---|---|---|
| D1a 　| **△** 地合い良好なら `支持線〜支持線+0.15ATR`。RRは25日線または直近抵抗線までで判定。安全重視ならVWAP再回復確認 | **△** VWAP回復だけでは不可。`VWAP15分維持＋安値切り上げ＋高値更新` でD3化なら小さく可 | **△** 後場VWAP上維持なら小さく可。25日線接近時は利確圧に注意し、持ち越しは25日線手前で評価 |
| D1b 戻り途中・25日線遠い | **×〜△** 基本は危険。支持線が明確でRR2.0以上なら最小ロットのみ | **△** VWAP上でもD3未達なら監視。入るならD3条件成立後 | **△〜×** 出来高60%以上かつ終端60%以上がなければ見送り |
| D1 判定保留 | **×** ATR距離不明なら `指値算出不可` | **△** D3条件を満たせば小さく可。ただし通常サイズ不可 | **△〜×** 判定材料不足のため原則見送り |
| D2 底打ち候補 | **△** `支持線〜支持線+0.15ATR`。地合い良好時のみ。RR1.5以上なら試し可 | **△** VWAP15分維持なら試し玉候補。安値切り上げ、高値更新、終端60%以上が揃いD3化すれば○。出来高60%以上が望ましい | **△〜○** 後場VWAP上維持かつ終端60%以上なら小さく可。当日高値圏でなければ持ち越しは弱い |
| D3強 | **○** `VWAP-0.25ATR〜VWAP` または `支持線〜支持線+0.25ATR`。RR良好なら可 | **◎** `VWAP15分維持＋出来高80%以上`。小さく可。通常サイズは25日線奪回後 | **◎** 後場VWAP上維持なら持ち越し候補。25日線未満のためサイズは抑える |
| D3 | **○〜△** `支持線〜支持線+0.25ATR`。RR1.5未満なら見送り | **○** 小さく可。`VWAP〜VWAP+0.20ATR`。出来高増加または前日高値試しで信頼度を上げる | **○〜△** 後場VWAP上維持なら可。出来高不足またはN/Aなら持ち越しは慎重 |
| D3弱 | **△** 支持線近辺のみ。RR2.0以上で最小ロット | **△** 前日高値試しまたは終端70%以上なら小さく可 | **△〜×** 後場VWAP維持でも出来高が戻らなければ監視継続 |

D2のVWAP回復は、D3必須条件を満たさない段階ではD2のままであり、評価は△とする。
D3条件がすべて成立した時点でD3へ再分類し、○以上の評価を適用する。

### 10.9 指値帯とRR

- 指値帯はATR14と採用支持線またはVWAPから計算し、価格へ展開して表示する
- RRのエントリー価格は、指値帯上限を使用して保守的に計算する
- 損切り価格は `採用支持線 - 0.35ATR` とする
- 目標価格は、25日線と現在値より上の直近抵抗線のうち、エントリー価格より上で最も近い価格とする
- `RR = (目標価格 - エントリー価格) / (エントリー価格 - 損切り価格)` とする
- ATR14、採用支持線、目標価格のいずれかが欠損する場合は `RR算出不可` と表示する
- ATR14または採用支持線が欠損して指値帯を計算できない場合は `指値算出不可` と表示する
- 「地合い良好」は当面は裁量条件とし、US Market指標からの自動判定には使用しない

## 12. 単一銘柄Technical出力の崩れ警戒スコア

単一銘柄Technical出力および Technical Summary 一覧では、25日線の上下にかかわらず崩れ警戒を表示する。
崩れスコアは、5日線・25日線を含めない価格構造スコアとする。値が欠損して条件を評価できない場合は加点しない。

実装では各条件を識別子・成立可否・加点を持つ `SignalAtom` として保持する。5日線・25日線の状態も `SignalAtom` として保持するが、崩れスコアには加点せず、C2陥落理由の三軸判定にのみ使う。

| 条件 | 点数 |
|---|---:|
| 現在値がVWAP未満 | +1 |
| 直近3営業日の安値切り上げがすべて不成立 | +1 |
| 直近3営業日の高値更新がすべて不成立 | +1 |
| 終端位置が40%未満 | +1 |
| 出来高20日平均比が100%超、かつ陰線または上値失速 | +1 |
| 直下支持線までの距離が0.7ATR超 | +1 |

5日線軸は次の条件から短評とC2陥落理由を作る。崩れスコアには加点しない。

| 条件 | 内部理由 |
|---|---|
| `ma5_slope <= 0` | 5日線下向き |
| `ma5_slope < ma5_slope_prev` | 5日線鈍化 |
| `ma5_slope < ma5_slope_3d_ago` | 5日線失速 |

短評では、該当なしなら `5日線良好`、該当数が1〜2なら該当文言を連結、3条件すべて該当なら個別文言を削除して `5日線悪化` のみ表示する。

25日線軸は `当日25日線 < 5営業日前25日線` を `25日線下向き` とする。横ばいは25日線悪化として扱わず、崩れスコアにも加点しない。

25日線の崩れ判定では、傾きの絶対値や、傾きが5営業日前より悪化しているかは使わない。
現行実装は、当日25日線と5営業日前25日線の水準だけを比較する。

| 判定 | 条件 | 意味 |
|---|---|---|
| 25日線上向き | `当日25日線 > 5営業日前25日線` | 中期線は上向き |
| 25日線下向き | `当日25日線 < 5営業日前25日線` | 中期線は下向き。C2陥落理由の補助軸に使う |
| 25日線横ばい | `当日25日線 == 5営業日前25日線` | 悪化扱いしない |
| 判定不可 | 当日25日線または5営業日前25日線が欠損 | 25日線軸では加点・陥落理由に使わない |

25日線下向きは単独では C2 に陥落させない。`5日線下向き` と同時成立した場合は `下行初動`、崩れスコア2点以上かつ価格構造悪化と同時成立した場合は `構造崩れ` として扱う。

ランキング分類では、崩れ警戒スコアから C2 陥落条件を派生させる。

25日線以上の A / C 系ランク（A2 / A1 / A1弱 / C1）では、次のいずれかを満たす場合のみ `C2 崩れ警戒` へ分類する。

| 区分 | 条件 |
|---|---|
| 即時崩れ | 下表 T1〜T4 のいずれかが成立 |
| 下行初動 | 5日線下向き、かつ25日線下向き |
| 下行初動 | 5日線下向き、かつVWAP割れ |
| 構造崩れ | 25日線下向き、かつ崩れスコア2点以上、かつ価格構造悪化 |
| 高リスク | 崩れスコア4点以上 |

| トリガー | 条件 |
|---|---|
| T1 VWAP明確割れ＋終端位置低下 | `現在値 < VWAP - 0.2 * ATR14` かつ終端位置低下 |
| T2 VWAP明確割れ＋安値切り上げ失敗 | `現在値 < VWAP - 0.2 * ATR14` かつ安値切り上げ失敗 |
| T3 出来高陰線/上値失速＋終端位置低下 | 出来高陰線/上値失速、かつ終端位置低下 |
| T4 支持線崩落 | 直下支持線が遠い、かつVWAP割れ |

5日線のみ、25日線のみでは C2 へ陥落させない。C2 陥落条件に達しない場合、崩れスコア1点は `要確認`、2〜3点は `軽度警戒` と表示し、ベースランクを維持する。

### 12.1 C2陥落理由の表示

単一銘柄Technical出力でランクが C2 の場合、短評に次の形式で陥落理由を表示する。Technical Summary 一覧には従来どおりランクと崩れスコアのみを表示し、陥落理由は表示しない。

```text
{崩れ区分}：{陥落理由}
```

複数条件が同時に成立した場合も表示する理由は1件とし、次の優先順位で決める。

| 優先順位 | 陥落理由 | 判定条件 |
|---:|---|---|
| 1 | 即時崩れ：VWAP明確割れ＋終端位置低下 | T1 |
| 2 | 即時崩れ：VWAP明確割れ＋安値切り上げ失敗 | T2 |
| 3 | 即時崩れ：出来高陰線/上値失速＋終端位置低下 | T3 |
| 4 | 即時崩れ：支持線崩落 | T4 |
| 5 | 下行初動：5日線下向き＋25日線下向き | 5日線下向き、かつ25日線下向き |
| 6 | 下行初動：5日線下向き＋VWAP割れ | 5日線下向き、かつVWAP割れ |
| 7 | 構造崩れ：25日線下向き＋崩れスコア中以上＋価格構造悪化 | 25日線下向き、かつ崩れスコア2点以上、かつ価格構造悪化 |
| 8 | 高リスク：崩れスコア高リスク | 上記が不成立、かつ崩れスコア4点以上 |

**定義補足：**

- **陰線：** `終値 < 始値` かつ実体が `0.15ATR` 以上
- **上値失速：** 上ヒゲが当日値幅の45%以上、かつ実体の1.5倍以上
- **直下支持線：** 現在値より下にある25日線、前日安値、20日安値、75日線、60日安値のうち最も近い価格
  - 候補がない場合、またはATRを取得できない場合は距離条件を加点しない
- **25日線下向き：** `当日25日線 < 5営業日前25日線`
- **5日線傾き比較：**
  - `ma5_slope = 当日5日線 - 前日5日線`
  - `ma5_slope_prev = 前日5日線 - 2営業日前5日線`
  - `ma5_slope_3d_ago = 3営業日前5日線 - 4営業日前5日線`

### 12.2 崩れスコアのランク別ラベル表示

表示は `崩れ {score}/6：{ラベル}` 形式とする。

| ランク | 0〜1点 | 2〜3点 | 4〜6点 |
|---|---|---|---|
| A*, B*, D2, D3, E | 崩れ軽微 | 上値重い | 崩れ警戒 |
| C1 | 押し目候補 | VWAP回復待ち | 押し目ではなく崩れ警戒 |
| C2 | 軽度崩れ | 崩れ警戒 | 買い不可 |
| D1 | 戻り良好 | 25日線奪回待ち | 戻り売り警戒 |

表示例: `崩れ 4/6：崩れ警戒`

### 12.2.1 単一銘柄出力の実戦短評

単一銘柄Technical出力では、ランク別ラベルの代わりに実戦用の短評を表示する。
スコア計算とC2陥落条件は変更せず、短評だけを次の点数帯で表示する。

| 崩れスコア | 短評 | 補足 |
|---:|---|---|
| 0〜1 | 候補 | 買い条件は別確認 |
| 2〜3 | 条件付き候補 | 後場VWAP上維持・終端60%以上を確認 |
| 4 | 原則回避 | 新規買い回避。前場深押し指値は避ける |
| 5 | かなり回避 | 例外条件が揃う時だけ短期リバ検討 |
| 6 | ほぼ触らない | 構造回復まで見送り |

例外条件は、後場VWAP回復、VWAP上維持、終端70%以上、出来高増加、
25日線回復または明確な支持線反発が揃う場合を指す。

表示例: `崩れ 2/6：条件付き候補｜後場VWAP上維持・終端60%以上を確認`

### 12.3 実装確認事項

- 現行モデルは `ma5`、`ma5_prev1`、`ma5_slope`、`ma5_slope_prev`、`ma5_slope_3d_ago` を保持する。
- 5日線短評は、該当なしなら `5日線良好`、該当数1〜2なら個別文言、3条件すべて該当なら `5日線悪化` と表示する。
- 崩れスコアの最大値は6点。5日線・25日線は崩れスコアに加点せず、三軸のC2陥落理由にのみ使う。表示分母、ラベル境界、既存テスト期待値を6点基準で統一する。

### 12.4 Technical Summary 一覧での表示と並び順

Technical Summary 一覧では、従来の `前日VWAP維持` 列を表示せず、代わりに `崩れスコア` 列を表示する。

列の表示形式は崩れ警戒スコアの数値のみとし、短評やラベルは表示しない。

各ランク分類のうち、B2 / B1 / A2 / A1 / A1弱 / C2 / C1 では、銘柄を崩れスコアの低い順に並べる。同点の場合は WatchList の順序を維持する。D1 / D2 / D3 / E は WatchList の順序を維持する。

## 13. 底打ち初動・ホールド判定

### 13.1 底打ち初動判定

底打ち初動判定は現在値が25日線未満の場合だけ表示し、
Technical Summaryランクが `D3` の場合を `成立`、それ以外を `未成立` とする。

### 13.2 ホールド判定

ホールド判定は次の条件を使う。直下支持線の距離はATR14で正規化する。
条件が重複する場合は上から順に評価し、最初に一致した判定を採用する。
どの条件にも完全一致しない場合は `△` とする。

| 判定 | 条件 |
|---|---|
| × | VWAP未満、25日線未満、直近3営業日の安値切り上げがすべて不成立、直下支持線まで0.7ATR超をすべて満たす |
| △ | VWAP以上だが25日線未満、または終端位置50%未満、または出来高20日平均比80%未満 |
| ◎ | 25日線以上、VWAP以上、終端位置50%以上、出来高20日平均比80%以上、直下支持線まで0.7ATR以内をすべて満たす |
| ○ | VWAP以上、かつ「25日線以上または25日線まで0.7ATR以内」、かつ直近3営業日の安値切り上げが1つ以上 |
| △ | 上記のいずれにも一致しない |

直下支持線は現在値より下にある25日線、前日安値、20日安値、75日線、60日安値のうち最も近い価格を使う。支持線候補がない、またはATR14が欠損・0で距離を算出できない場合は、支持線が遠いとは判定しないため、この理由だけで `×` にはしない。

株価・VWAP・25日線・25日線乖離率のいずれかが欠損し、ホールド判定の前提を満たせない場合、単一銘柄Technical出力ではホールド判定を `N/A` とする。その他の補助値が欠損して上表の条件に一致しない場合は、既定値の `△` とする。現行実装では上側抵抗線までの余地や25日線傾きはホールド判定に使わない。

## 14. US Market Technical Summary

Technical Summary の冒頭には US Market セクションを表示する。

対象は以下の通り。

- `NASDAQ総合`
- `SOX指数`
- `NVIDIA`
- `GRID`
- `日経先物`
- `銅先物(COMEX)`
- `WTI原油`

各行は yFinance の日足から以下を計算する。

| 指標 | 計算 |
|---|---|
| 直近値 | 当日終値 |
| 前日騰落 | 当日終値 - 前日終値 |
| 5日移動平均乖離 | 25日線乖離率と同じ方式で計算 |
| 25日移動平均乖離 | (現在値 - 25日線) / 25日線 * 100 |
| RSI14 | 14本ベースで計算 |

US Market の取得失敗は Technical Summary 全体の失敗にしない。
取得できない指標は skipped として理由を保持し、表示可能な指標だけを出力する。
