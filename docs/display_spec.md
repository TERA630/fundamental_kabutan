# 表示仕様書（現行実装準拠）

## 1. 目的
本仕様書は、現行GUIでの表示内容を仕様として整理する。

## 2. 対象範囲
- GUI画面上の固定ラベル、ステータスメッセージ
- 出力テキスト（分析結果）内の株探セクション表示
- 表示に必要な入力データとフォールバック時の表示

## 3. 責務分離

### 3.1 データ層
- 監視銘柄読み込み: `app/data/watchlist_repository.py`
- yFinance株価取得: `app/data/market_data_provider.py`
- 株探データ取得（HTML解析・Web取得）: `app/data/kabutan_repository.py`
- キャッシュ: `app/data/file_cache.py`

### 3.2 ドメイン層（モデル/ユースケース/出力生成）
- モデル: `app/domain/models/kabutan_forecast.py`
- ユースケース:
  - 分析オーケストレーション: `app/domain/usecases/fundamental_analysis.py`
  - 株探予想取得: `app/domain/usecases/kabutan_forecast.py`
- 出力生成:
  - 基本出力: `app/domain/builders/fundamental_output.py`
  - 株探セクション追記: `app/domain/builders/kabutan_output.py`

### 3.3 GUI層（画面表示/表示用データ）
- 画面部品描画: `app/gui_view.py`
- 表示文言生成: `app/gui_view_model.py`
- 画面状態: `app/gui_state.py`
- イベント仲介: `app/gui_controller.py`
- 画面イベント処理: `app/gui.py`

## 4. GUI表示仕様

### 4.1 固定表示
- ボタン:
  - `監視銘柄ファイルを開く`
  - `株探HTMLフォルダを選択`
  - `取得`
  - `コピー`
  - `保存`
- 株価ソース表示: `株価: yFinance固定`

### 4.2 ステータスメッセージ
- 初期: `監視銘柄ファイルを読み込んでください。`
- 監視銘柄ロード完了: `{count}件の監視銘柄を読み込みました。`
- 銘柄選択: `銘柄を選択しました。取得ボタンを押してください。`
- 必須不足: `先に監視銘柄ファイルと銘柄を選んでください。`
- 取得中（株探表示優先を明示）:
  - `取得中: {name} ({code4}) / 業績=株探(HTML優先) / 指標=yFinance`
- 生成完了（株探表示優先を明示）:
  - `生成完了: {name} ({code4}) / 業績=株探(HTML優先) / 指標=yFinance`
- キャッシュ表示: `キャッシュ表示: {name} ({code4})`
- コピー不可: `コピーするテキストがありません。`
- コピー完了: `クリップボードにコピーしました。`
- 保存不可: `保存するテキストがありません。`
- 保存完了: `保存完了: {path}`
- 株探HTMLフォルダ選択後: `株探HTMLフォルダを設定しました（出力キャッシュをクリア）。`

## 5. 出力テキスト仕様（株探セクション）

### 5.1 セクション見出し
- `■株探 通期業績推移`
- ソース表示:
  - HTML解析成功時: `株探ソース: HTML`
  - 取得不可時: `株探ソース: 取得不可`
  - メッセージ付き: `株探ソース: 取得不可 ({message})`

### 5.2 テーブル表示
- ヘッダ: `売上 / 営業益(率) / 経常益(率) / 最終益 / 1株益 / 1株配当`
- 行（優先表示）:
  - 前々々期実績: `YYYY年`
  - 前々期実績: `YYYY年`
  - 前期実績: `YYYY年`
  - 今期予想: `YYYY年(予)`
  - 来期予想: `YYYY年(予)`
- 数値フォーマット:
  - 金額: `value/100` を `x,xxx.x億` 形式
  - 比率: `x.x%`
  - EPS/配当: `x.x円`
  - 欠損: `N/A`

### 5.3 前年度営業利益成長率(%)
- 行単位で `calc_operating_growth_rate` を適用（前行の営業利益対比）
- 先頭行は比較元がないため `N/A`

### 5.4 予想チェーン
-　廃止
### 5.5 株探データ欠損時
- `データーが取得できません`の表示

### 5.6 FYデータ欠損時のGUI表示
-　削除

### 5.7 指標ブロックの年次表示（変更）
- 指標ブロックの表示順は下記とする。
  1. `株価：xxxx円 / PBR x.xx / ROE xx.x%`
  2. `業種：xxxx    時価総額：xx,xxxx.x億円(xx型)`
  3. 業種の下は一行あける｡
  4. `PER：202x年実績 xx.x倍／202x年(実績/予) xx.x倍／202x年(予) xx.x倍`
  5. `配当利回り：202x年 x.xx%／202x年 x.xx%／202x年 x.xx%`
 
- PERおよび配当利回りは、株探の行データに含まれる「修正1株益」「修正1株配当」を基準に算出する。
  - 表示に使用する年は、株探行データから取得できた年を基準に決定する。
  - PER行の表示年は、修正1株益が取得できた最新年を `Y_per` として `Y_per-2, Y_per-1, Y_per` の3年を表示する。
  - 配当利回り行の表示年は、1株配当が取得できた最新年を `Y_div` として `Y_div-2, Y_div-1, Y_div` の3年を表示する。
  - PER行と配当利回り行の表示年は独立に判定する（無配・配当欠損でもPER表示は継続）。
  - 年ラベルは、予想値なら `YYYY年(予)`、実績値なら `YYYY年(実績)` とする。
  - `PER = 株価 / 修正1株益`
  - `配当利回り(%) = 修正1株配当 / 株価 * 100`

### 5.8 summary_rows 非依存方針（改訂）
- 指標ブロック（PER/配当利回り）およびGUI表示文言の算出に `summary_rows` は使用しない。
- これらの表示は `market_snapshot` と株探セクション行データを表示用に整形したドメイン出力に依存する。

## 6. 株探データ探索仕様（表示に影響する条件）
- HTMLフォルダ未設定: `取得不可 (HTMLフォルダ未設定)`
- 探索順序:
  1. ファイル名（stem）に4桁コードを含むHTML/HTM（正規表現一致）
- 取得モード:
  - 既定: HTML優先、Webフォールバックなし

## 7. キャッシュと再表示
- 出力キャッシュキー: `code4` + `kabutan_html_dir`
- 監視銘柄再読込・株探HTMLフォルダ再選択時は出力キャッシュをクリア
- 同一キーで取得済みの場合は再計算せず `キャッシュ表示` ステータスで描画

### 7.1 株探HTMLフォルダの自動復元（Phase1）
- データ層は最後に取得成功へ使用した株探HTMLフォルダを永続キャッシュする。
- GUI起動時にキャッシュ済みフォルダを読み込み、存在かつディレクトリであれば自動復元する。
- 次回実行では復元先フォルダで取得を試みる。
- 復元先が無効（未存在/ディレクトリでない）な場合のみ、取得操作時にGUIから再選択を促す。
- ユーザーがGUIで株探HTMLフォルダを再選択して確定した場合、永続キャッシュを更新する。

## 8. 備考
- 本仕様は現行実装準拠であり、将来のWeb優先モードや複数ソース統合表示は対象外。

## 9. quarterly_display_spec.md について
- 現行リポジトリでは四半期専用の独立仕様書は持たず、本書（`display_spec.md`）を表示仕様の単一ソースとする。
- 将来、四半期表示を正式対応する場合は、ドメイン層のモデル/ユースケースを分離したうえで別章または別紙として追加する。
